## 2 交付

1. `0003_repositories`：规范 URL 唯一、owner/latest task 外键、状态/字节数约束、分页索引；非空降级在 DDL 前整条路径检查，旧认证与任务数据保留。
2. A07 先检查权限、幂等重放、预计容量、DNS/TLS/smart HTTP，再同事务创建 repository/task/outbox/audit；同键异 URL 冲突，不同键重复仓库不创建任务。A08/09 提供共享分页目录、元数据及最新 successor，隐藏存储路径。
3. HTTPS/443、无凭据、ASCII DNS/IPv4、全部 A/AAAA 安全检查；DNS 失败或混入不安全地址即拒绝。所有重定向拒绝，每次 CONNECT 重新检查并绑定数值 IP/实际 peer，TLS 校验原域名；不能通过 alternate object URI 改用其它主机或协议。
4. 原生 Git 受控 bare 克隆：禁用凭据助手/全局系统配置/模板 hook/工作区检出/子模块/外部 URI，限制进程时间、磁盘/传输大小和输出。默认900秒、单仓库2GiB，Worker 并发1；每租约使用独立 UUID 目录。
5. 元数据、storage_key 与任务成功以有效 token/租约原子发布。取消、超限和旧租约只清理本次未发布目录；数据库提交结果不确定时保留文件，避免删除已发布仓库。空仓库无法确认分支/HEAD 时返回 null。
6. `/repositories` 和 `/repositories/:id`：添加、分页、状态/错误、默认分支/HEAD/大小、关联任务；任务详情增加克隆结果链接与字节数。Viewer 只读，重新登录可返回详情，支持移动端。沿用结果不确定时同键重放及迟到请求防护。
7. D 盘 bind mount 共用 API/Worker 存储；初始化只处理专用根和 objects 两层。受理/执行前要求两倍仓库预算+2GiB余量，运行周期继续检查。命令普通模式也硬性拒绝无法容纳已知增长的操作，不改用 C。fresh 验收使用独立路径和新卷。
8. Broker 故障日志改为稳定分类码，避免第三方重连堆栈/URL进入 Worker 日志；保留 TASK_BROKER_CONNECTION_LOST / UNAVAILABLE 及业务 task ID 诊断。

首次验收的失败保留用于定位，最终结果独立记录，未跳过测试或改成模拟通过：

- 大小限制的定向测试起初同时触发传输限制，调整注入以单独验证磁盘分支；Windows Git pack只读属性随后揭示清理问题，仅对验证范围内本次文件移除只读属性后重试删除，不修改系统ACL。
