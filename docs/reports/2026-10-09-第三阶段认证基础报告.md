# 第三阶段认证基础报告

- 日期：2026-10-09
- 范围：个人 `wang` 分支，`bootstrap-application` 任务 2.1、2.2，及 2.3 的权限校验基础。
- 起点：第二阶段提交 `1ef62f0ee2660f3eef4791a64cdf07e5f3ce8627`。
- 结论：最小认证与认证迁移可交付；实际任务接口权限、可靠任务和登录页面保持后续范围。完整最终复核结果见下方验收表。

## 1 本阶段交付

1. 增加版本化 Alembic 迁移 `0001_auth`、ORM 及 `user/auth_session/operation_log` 三张表，采用 InnoDB、UTC 微秒时间、UUID/哈希 ascii_bin、唯一键、CHECK、索引和 RESTRICT 外键。升级保留已有平台标记表；认证表非空时拒绝 downgrade。自动生成/一致性检查只比较声明的应用表，避免建议删除无关表。
2. 实现 A01～A04：登录、退出、refresh 和当前用户查询；密码 Argon2id，固定算法 JWT；每次受保护请求验证活动用户、DB 会话及最新角色。
3. 实现不透明 refresh 的哈希入库、HttpOnly/SameSite/路径限定 cookie、行锁与 generation 轮转、7 天绝对寿命、CSRF 和精确 Origin 校验。退出立即撤销会话，现有 access 随即失效；临近到期时 cookie/access 均不延长绝对寿命。
4. 实现 Redis Lua 的用户名/IP 独立共享限流，默认各 5 次/60 秒；错误凭据不区分未知/错误/禁用，Redis 故障拒绝登录并返回安全 503。审计和会话变更同事务，审计失败不提交或签发 cookie。
5. 提供显式一次性 Admin seed，无默认账号密码、不公开注册、不自动重置已存在账号。角色层级和任务归属 helper 已实现，实际任务接口尚未存在，任务 2.3 不勾选。
6. 修复容器更新时 Web 代理缓存 API 旧地址的问题：Nginx 使用 Docker 内置 DNS，5 秒刷新解析，保留原请求 URI。回归验收强制 API 更换地址并保持原 Web 容器运行。[Nginx resolver/proxy_pass 依据](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_pass)。
7. 同步 API/数据库、测试、追踪、OpenSpec、启动和空间规划说明；基础页改为准确说明认证已实现、任务/操作页面待开发。

## 2 验收结果

最终完整运行 **28 项测试全部通过**（87.41 秒），包括 15 项认证/迁移专项、1 项实际 HTTP 认证、1 项 API 地址变化回归及原有 11 项平台检查。存在 1 条 Starlette 对 TestClient 使用 httpx 的弃用提示，不影响当前通过；后续升级测试依赖时处理。

| 验收项 | 实际内容 | 结果 |
|---|---|---|
| SEC-AUTH、INT-MIGRATION | MySQL 临时库验证登录/刷新/退出、CSRF/Origin、JWT 缺字段/过期/篡改/错误 issuer/audience/algorithm、禁用、并发刷新、独立共享限流、事务回滚、绝对寿命、迁移约束/回滚/版本拒绝 | 通过 |
| SEC-RBAC 基础 | Viewer/Member/Admin 层级、最新 DB 角色、任务归属 helper | 通过；实际任务接口权限未验收 |
| 完整 HTTP 与平台回归 | 五组件真实启动；Web 代理登录→me→refresh→logout；DB 审计；Redis 停止/恢复、MySQL/Redis 重启持久化、Worker ping；API 地址变化代理恢复 | 通过 |

首轮认证专项通过 11 项；扩展复验暴露 API 重建后的旧代理地址，已修复并增加实际地址改变的回归。迁移一致性检查发现平台标记表可能被视为待删除，已限定检查范围并实测无关表保留。这些问题关闭后才提交。

测试采用实际 MySQL/Redis，不以 SQLite 代替约束或以单进程内存代替共享限流。认证服务在 TestClient 与实际容器 HTTP 两条路径验证；审计异常和认证 Redis 异常采用明确注入，基础平台另实际停止 Redis。任务恢复故障注入尚未开展，Worker ping 不代表业务执行。

## 3 本机配置与数据

升级前只存在 `platform_probe/platform_volume_probe`，均已保留。专用开发库已升级至 `0001_auth` 并初始化应用管理员 `wang-admin`。随机密码仅位于 Git 忽略的 `.env`；报告、仓库、聊天和命令输出不含密码/JWT/cookie。重复 seed 验证凭据不变；已有账号后的空库 downgrade 路径不会用于本机开发库。

迁移测试各自创建随机前缀临时库，结束撤销该库授权并删除临时库；真实 HTTP 验收保留合法审计及已撤销会话。DNS 回归的临时容器无秘密、端口或数据挂载，复用既有镜像，结束删除自身。不会删除卷或执行全局 prune。交付后停止本项目五组件，保留镜像和数据，继续时按 [认证与迁移](../development/认证与数据库迁移.md) 启动。

系统 Python 3.13、PATH、Windows 账号/SSH ACL/config/known_hosts 均未修改；项目仍使用 D 盘 Python 3.11/.venv。未安装模型、CUDA 或额外系统软件。
