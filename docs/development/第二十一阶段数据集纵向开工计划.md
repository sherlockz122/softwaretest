## 本批目标

把第二十阶段的本机离线公开资产/review工件，接成应用内可创建、查询、追溯的用途分离数据集：迁移/任务/权限/API/页面组成一条完整链路，准备可复现的研究12数值导出。优先现有ApacheJIT固定快照；不在此批训练模型或承诺新增格式、多语言/类型资格。

1. 建立对应OpenSpec proposal/specs/design/tasks；先明确public research、生产十四维和历史回放的版本/用途区别，原资产与审计引用、不变成员/切分摘要、拒绝原因、可用时间及资格字段。明确公开数据研究目标是后验发布弱监督二分类，不冒充历史在线模拟。
2. 新增数据集持久化/迁移与安全降级，旧0001～0008迁移不重写；旧FeatureRun和false标签资格不回填。固化原始/派生来源引用、规则、canonical仓库与SHA去重、冲突隔离、时间/项目分区和能力门槛。
3. 复用可靠任务/outbox/租约/栅栏/审计实现dataset创建，A17～19与Member/Viewer/Admin权限相衔接。只接受受控资产标识及允许的参数，不让请求任意读取本机路径。任务幂等、取消、失败/重试与原子发布可恢复，半成品不被训练消费。
4. 实现应用页面的创建/列表/详情、任务状态、分区/质量/来源和明确限制；按当前04/08路由合同，不照外来原型旧编号。业务操作无需用户理解实现细节，限制应足以帮助作出正确用途选择。
5. 形成研究12数值导出与稳定成员/分区工件：原fix仅标签元数据，不作为已知FIX特征；不补缺失LT或类型；两类可行性、同canonical/SHA隔离与冲突处理在导出前验收。raw_archived/normalized不能自动晋升research_binary，更不能晋升historical/candidate。

若单批复杂度过高，先报告并同步总计划/本页/任务，按可运行纵向切片拆分；不能跳过验收或暗中标全部完成。首条LR/RF训练/模型注册与两类指标安排下一批，成熟后再扩展其余模型与预训练语义P1。质量线继续有限原生对象/筛选/覆盖核验，缺证Unknown不阻塞正确限定的工程工作。

- 真实MySQL迁移/版本兼容/安全降级、旧环境及独立新卷，旧v1/v2与认证任务回归。

- 真实Worker取消/故障/重试接续/原子发布，重复请求不制造重复版本；成员和证据不可变，旧资产/review不变。

- 锁定依赖、ruff/格式/前端构建、安全扫描、strict OpenSpec、链接/API编号/OpenAPI逐项核验；合适的全量回归与精确SHA CI，不借本次准备或第二十阶段结果代替。

1. 开工读取00、最新总计划、本批指南、文档更新/遗留及上一报告；检查wang工作区/远程HEAD、保护用户材料，明确输入、成功标准、规模和退路。
2. 检查项目Python3.11.16 `.venv`，默认Python3.13不改；按需启动Docker/本批服务并验schema/健康。实测D空间、估新增与临时峰值，用命令包装器ExpectedGrowthGiB；D不足先停报告，不转C。
3. 先建立或更新OpenSpec可验收正常/异常/边界与任务，再分小步实现；问题/证据改变顺序时同步决策、计划、追踪和遗留并告知用户。
4. 执行本批专项及必要完整真实回归、故障恢复和独立新环境验收；失败定位修复复验，保留原失败，不削弱断言或重复累计用例。
5. 编写阶段报告，同步规格/指南/规划/OpenSpec/追踪/文档更新/遗留；记录结果、局限、资源和下一批前置，产物/测试/失败证据留D的runtime用于debug。
6. 守卫核对源/数据/用户文件，显式文件清单暂存；再查wang，正常提交/推送仅origin/wang。精确最终SHA的Wang quality五个必需步骤成功才报告远程验收，不用先前提交CI冒充；main和其它分支不写入。
7. 结束核对零活动任务、按需优雅停项目服务及后台，保留正常数据库/Redis卷与数据；报告完成/遗留/下一步，等待用户下一批指令。
