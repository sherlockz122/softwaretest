# 外来材料吸收与处置清单

2026-10-14，按 [权威决策](../decisions/2026-10-14-基线权威与外来材料隔离.md) 生效。本页完整记录日常开发需要的吸收结论，后续不依赖原始原型或外来探针来决定实现。

## 已吸收并需继续遵守

- 以用户任务组织页面：仓库→数据质量/证据→用途明确的数据集→训练/评估→候选风险；只有能力实际交付才开放对应操作。异步任务提供进度/取消/重试/来源下钻，现行路由与权限见04/08及已部署页面。
- 多步创建应先显示来源、目的、兼容性与限制，再确认；错误/空/加载/未认证/取消等状态有明确处置。当前unknown和能力不足不能以空图或“可训练”隐藏。
- Git/数据链用完整SHA和固定版本，保存原始/派生/规则/时间/来源摘要。行级证据与提交级统计分别报告，避免把重复命中当独立缺陷。
- 注释、空白及批量变更可能造成SZZ噪声，必须按版本保留过滤、失败计数和限制；噪声判断需要独立证据，规则命中不是gold。
- 性能、空间和失败均以实际测量报告，冷热、仓库、规模、路径/设备及执行口径分别记录，不将探针数字外推产品全规模。
- 课程有效要求已纳入自有01/05/06/07：至少20个关联核心User Story与优先级/验收、Git/PR非作者审阅、OpenSpec全链路、看板/迭代/周报、至少核心E2E、正常/边界/异常、至少两项已验证非功能需求及所选项证据、缺陷闭环和最终12分钟展示。保留课程六经典+两深度模型要求；归档旧来源不免除未完成项。

## 明确不采用的冲突/不足

| 外来表述 | 我们的有效合同与处理 |
|---|---|
| 公开注册、四种产品角色直接作为权限 | 默认关闭公开注册；Viewer/Member/Admin为有效RBAC；用户画像与权限角色分开 |
| time_ordered 8:1:1 | 默认70/15/15，边界固定、同时间稳定规则、独立仓库分组及用途控制；train-only处理，test不择优 |
| 未实现可靠重构检测就称RA-SZZ | baseline SZZ；unknown/成熟度/覆盖/知识资格独立验收，不把未命中当完整clean |
| A16创建数据集等旧编号/旧路由 | A16当前为特征质量；A17创建、A18列表、A19详情数据集；实际实现与04/OpenAPI一致后开放 |
| 九模型或仅默认分支预测即满足全部目标 | 课程八模型矩阵保留，语义/预训练融合P1增量独立验收；合入前candidate/ref/diff依旧核心目标 |
| author时间统一替代所有时钟 | 保留author、committer事件、实际acquired、证据/知识可用和review时间；遵守各用途版本，不回填历史 |
| 宽泛fix/patch/close词即缺陷修复 | 使用现行有边界规则/Issue证据分级/误报与复核；普通票号或关闭措辞不自动高等级Fix |
| 单仓库六个月窗口“已定”通用参数 | 不采用外部固定值；现行historical-horizon-replay-v1默认90天/7天延迟是预声明实验政策，需按真实来源测量而非金标事实 |
| 注释命中52个就全判误标、9.9%即产品缺陷率 | 外部结果未独立复现和专业审阅，不晋升真值/噪声率/跨语言结论 |
| 原始seed重复执行重置账号密码/角色 | 使用packages.auth.bootstrap保留已有账号；旧seed仅拒绝退出2；无效provision配置不进入新夹具 |
| 旧db工厂直接复用、脚本直接放Worker | 已归档；未来连接/事务/生命周期按当前Connections与可靠任务合同实现。外来probe无timeout/退出码检查及异常跳过不能直接投产 |

## 继续评估的事情

多语言/类型/定位、预训练污染与公平评估、真实来源的独立复核和负例覆盖仍按自有最新规划推进。有益新证据可以改进我们的标准，但先固定版本、有限核验、写入决策/场景/测试和报告，不重新引入并行旧文档。
