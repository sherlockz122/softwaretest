## 1 使用规则

本矩阵是过程证据索引，不替代需求、OpenSpec、实现或测试报告。

1. User Story 进入 Sprint 前必须能定位到 OpenSpec、设计模块和计划测试。
2. PR 标题包含 US 编号，正文链接 change/task。
3. Done 必须同时具备实现合并、验收通过和证据登记。
4. 尚未创建的 change 标记为“计划”，不得假装已经存在。
5. 实施后将 PR、测试报告、截图或演示链接填写到证据栏。
