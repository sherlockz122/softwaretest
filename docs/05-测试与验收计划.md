测试不仅验证功能是否返回结果，还要证明数据口径正确、模型评估无泄漏、长任务可恢复、安全边界有效，并形成课程要求的可核验证据。

## 3 核心 E2E

### E2E-BOOT 框架运行（先于业务 E2E）

工程实现后，以真实 MySQL、Redis 和独立 Celery Worker 验证：空库迁移与预置账号 → 登录 → 创建诊断任务 → 任务页查看 queued/running/succeeded → 退出并拒绝已撤销 access token。诊断接口只在 dev/test 启用，不执行 Git 或模型操作。

专项补充：SEC-AUTH/RBAC 验证 refresh 轮转、CSRF、禁用账号和任务归属；INT-OUTBOX 验证 DB 提交后 Redis 不可用、发送后写回失败及重复投递；REL-LEASE 验证 kill Worker、过期令牌拒写与有限 successor；REL-CANCEL 验证完成/取消及并发 retry。契约详见 API 文档第 10 节及 `bootstrap-application`，真实故障测试不能以 mock/eager mode 冒充。

第三阶段实施证据见 [认证基础报告](reports/2026-10-09-第三阶段认证基础报告.md)：A01～A04 经实际容器 HTTP 验收，MySQL 临时专用库验证迁移约束/空库回滚、并发刷新与事务回滚。角色和归属 helper 已验收，实际任务接口的 SEC-RBAC、业务恢复故障注入和 E2E-BOOT 保持未完成；不把基础平台故障测试扩大为任务恢复证据。

第一批只验收规格完整性、追踪关系及存储脚本的正常/失败/低容量行为；报告保存在 `docs/reports/2026-10-09-第一批准备任务阶段报告.md`。这不代表 E2E-BOOT、业务功能或非功能需求已经通过。

### E2E-01 历史数据 MVP

```text
Given 一个团队允许使用的公开小型 Git 仓库和固定提交窗口
When 成员添加仓库并完成解析、Fix 识别、baseline SZZ、Kamei 14、
     时间数据集、LR/RF 训练和测试集评估
Then 页面展示任务状态、标签/特征质量、测试指标和历史风险列表
And 每个结果可追踪 label_version、feature_version、dataset_id、model_run_id
And Unknown 未进入训练，预处理未使用 validation/test 拟合
```

异常路径至少包含：私网 URL 被拒绝；重复请求不产生重复数据；Worker 中断后从 checkpoint 恢复或明确失败；成熟标签不足时数据集创建失败并提供可行动原因。

### E2E-02 合入前评审

```text
Given 一个已有已发布模型的仓库、base=main 和尚未合入的 candidate ref
When 评审员发起候选变更预测
Then 系统只使用 base 时点可得的历史特征
And 返回校准概率、风险等级、Effort、主要影响因素与模型版本
And 风险队列默认按概率排序，风险密度只作为辅助
And 页面明确模型输出不是自动合并或拒绝结论
```

异常路径至少包含：candidate 不存在、base 不可达、diff 超限、模型与特征版本不兼容。

## 4 关键专项测试

### 4.1 仓库和安全

- HTTPS 合法仓库正常创建任务。
- `localhost`、IPv4/IPv6 私网、链路本地、保留地址和凭据 URL 被拒绝。
- 重定向到私网被拒绝；DNS 结果变化不会绕过校验。
- 仓库大小、克隆时限、diff 文件数和行数限制生效。
- 错误响应和日志不包含 token、本机路径、命令行、SQL 或依赖版本。

### 4.2 SZZ 和特征

- SZZ golden fixture 覆盖普通修改、重命名、空白/注释、首次新增、删除、二进制、合并及直接父提交。
- Fix 关键字正反例、Issue 类型和回滚语境均有测试。
- 第九阶段参数化英文边界/排除、实际TLS Issue适配/MySQL批次与复核事务、固定接受HEAD/有限历史/观测冻结、真实Worker SIGKILL及公开仓库Fix页面验证，依据 [Fix指导](development/Fix证据与验收.md)。完整结果随第九报告登记，先前切片不代替本批。
- 14 个特征逐一用手算结果断言，历史特征验证“当前提交之前”的时间边界。
- 同一 label/feature version 重跑幂等；版本升级不覆盖旧结果。

### 4.3 数据集和模型

- train、validation、test 时间区间不重叠，同一提交只出现一次。
- Unknown 不进入训练，valid/test 不经过重采样。
- scaler、imputer、tokenizer 和采样器只在 train 拟合。
- 所有插件输出 `[0,1]` 概率或明确失败；工件保存加载前后结果在容差内一致。
- 单类测试集时 AUC 类指标返回不可计算原因。
- 不同 dataset、label 或 feature version 默认不可直接比较和发布。

## 5 非功能验收

### NFR-01 安全

必须通过 SSRF、RBAC、敏感日志和不受信工件测试。Admin 专属接口对 Viewer/Member 返回 403；资源不存在与无权访问不得泄露敏感差异。

### NFR-02 可靠性

至少验证重复 Idempotency-Key、Worker 中断、MySQL/Redis 短暂不可用、stale 任务识别、有限重试和协作式取消。恢复后不得产生重复提交、标签、特征或模型 run。

### NFR-03 性能

在固定硬件、固定数据集和热模型条件下执行至少 100 次有效请求：

- 候选预测 P95 不高于 1 秒，不含首次模型加载和仓库拉取；
- 常用列表查询 P95 不高于 1 秒，`page_size <= 100`；
- 报告 P50/P95/P99、吞吐、错误率、环境、数据量和模型。
