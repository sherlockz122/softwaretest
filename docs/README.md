## 基线声明

本目录是 DefectGuard 后续需求分析、OpenSpec、开发、测试、评审和验收的唯一长期文档基线。自本基线建立后，不再直接使用 `softwarePrediction/` 中的 V1、V2 或 Word 模板指导开发。

外部材料与远程仓库旧文档的合并规则见《00 项目基线与版本合并决策》。需求变更必须同时更新受影响的本目录文档、OpenSpec change 和追踪矩阵。

## 使用规则

1. 产品级意图以 `01` 为准，技术实现约束以 `02` 至 `04` 为准。
2. 测试完成标准以 `05` 为准，协作与交付流程以 `06` 为准。
3. `07` 是证据索引，不替代需求、OpenSpec 或测试报告。
4. 每个功能开始编码前必须存在对应 OpenSpec 场景和任务。
5. 发生冲突时暂停实现，先形成明确决策并更新相关文档。

## 版本策略

本目录采用 Git 历史管理版本，不再通过复制 `V1`、`V2` 文件制造并行版本。文档标题不带版本号；版本、作者、评审和变更原因由提交、PR 与文档变更记录共同追踪。
