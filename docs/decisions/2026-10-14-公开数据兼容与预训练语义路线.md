# 公开数据兼容与预训练语义路线

2026-10-14；适用 wang 个人开发。用户提出公开数据保存/加载、标签类型、语言覆盖、数据质量及预训练语义方法的提醒。本决策修订后续优先级，不代表功能已经实现或团队批准。当前基线仍是第十九阶段，schema0008_features、35 个 API 编号和既有 v1/v2 合同保持。

## 核对原规划

原规格已包含 Kamei 14、message/diff 语义输入、TextCNN/DeepJIT-inspired、数据质量和防泄漏，2026-10-11 已明确不限定单一语言/团队。第十四～十九阶段实际交付 ApacheJIT 原始保存、审计及来源比较。但是通用公开数据导入/保存/恢复并未形成产品能力；缺陷类型和按语言验收不够具体；CodeBERT 被列为 P2。不能说这些提醒原先都已充分覆盖，也不能把词表/TextCNN 当成已交付预训练编码器。

## 决策

1. 将公开数据资产目录、不可变原始保存、安全导入、适配器及重新加载列为下一轮 P0；第一条真实适配 ApacheJIT，CSV/JSONL 逐步支持，其余源按适配器登记。能保存不等于能用于训练，模块/文件/函数/提交/行粒度分开。
2. 保留 Kamei 14 和 LR/RF 作为工程基线及可解释对照；产品语义路线提升至 P1：固定预训练编码器的冻结表征 + 简单分类器，然后同样本语义/专家特征融合，最后据证据选择有限微调。首个候选 CodeBERT-base，选定前验证语言、许可、权重来源、资源和预训练污染。它是候选，不预先宣称最佳。
3. 二分类风险仍是先交付目标；把标签粒度、可选多标签缺陷类型、类型证据/版本、位置标注、语言覆盖列为正式数据能力。缺少类型保留 null/unknown，位置标注不等于缺陷类型；禁止从二分类标签、SZZ 行或模型解释自动制造类型真值。
4. 首条非 Java 候选评估 OpenStack/Python、Qt/C++（JITLine 来源）及 ReDef/C/C++。分别核验 actual source、许可、采样、时间/仓库/粒度及两类；不按论文语言名自动认证每条记录。支持导入一种语言不等于模型对该语言有效，也不承诺立即得到跨语言统一模型。
5. 用用途能力分别管理原始存档、标准化导出、研究二分类、研究语义、历史回放、目标域候选发布、类型/定位任务。硬性不兼容拒绝，证据不足隔离或 Unknown；不过度要求全量人工金标。研究和当前训练工程继续推进，历史/产品发布按各自证据验收。

## 衔接与非破坏性迁移

已做的克隆/解析/Fix/SZZ/Kamei/成熟度/任务/权限/质量页继续复用。原材料及标签不改写；原始 source + adapter + transformation + label + feature + split + model 各自版本化，修订生成新资产/派生数据/特征版本，旧结果可重载。公开 12 数值研究基线（published fix 留元数据）不补 LT、不伪装产品 14 维；语义需要真实变更文本，不能从数值 CSV 生成。现行 source_validation=false 不回写。

A17～19 后续设计扩展用途/来源/能力与审计引用；新的公共导入/下载端点待独立 API 清单、OpenAPI、安全与迁移设计，不能复用仓库创建字段暗藏上传。语义独立工件/输入 schema，不给 14 维向量追加隐藏字段。未来特征版本和可见性字段须向后兼容并测试旧任务/模型/数据库恢复。旧生产适配器继续拒绝未经认证的 v2/外部版本。

原“P2 不在 Must 完成前启动”仍适用于未提升的附加模型；本次明确把受控预训练语义验证提升 P1，不再等八模型全部跑完才检查语义路线。六经典 + MLP/TextCNN 的课程验收矩阵保留；预训练/融合增加独立实验，不能靠改模型名字凑数量。单条可靠模型链路先于全套训练。

## 不阻塞全部开发的门槛

当下 106674 条公开数据可作为经审计的后验弱监督研究输入；候选产品输入/历史知识仍有缺口。28239 来源时钟吻合不证明全标签正确，334 clean 候选重叠不是 334 条确定误标，85 条定向复核不是噪声率随机样本。下一轮给每项缺口建可验输出；同批完成明确容量内的纵向切片，不反复以等待完美标签阻塞数据导入和 LR/RF 工程。

无需用户提供全量数据或自行寻找模型。开发负责合法公开源调研、适配、质量控制和受控实验。独立专业复核可提高小型金标集质量；GPU/云资源在资源探针证明必要后提出具体方案，不预设必须购买或上传代码。

## 研究依据与适用边界

- [JIT-Fine 作者仓库](https://github.com/jacknichao/JIT-Fine)：预训练语义与专家特征融合、行级定位提供路线依据；仓库公开输入包含 pickle，不照搬反序列化或论文训练设置。
- [JITLine 论文](https://arxiv.org/abs/2103.07068)：OpenStack/Qt 提供非 Java 候选来源，且其复现指出训练包含测试资料的影响；论文实验效果不能外推本产品。
- [CodeBERT 官方](https://github.com/microsoft/CodeBERT)和[官方模型卡](https://huggingface.co/microsoft/codebert-base)：预训练语言含 Python/Java/JavaScript/PHP/Ruby/Go；C/C++ 不在该六语言名单，跨域能力必须实测。
- [细粒度修复变更标注研究](https://arxiv.org/abs/2011.06244)：修复提交可能混入非修复变更，支持独立复核与保留不确定性，而非把 fix 全部行当缺陷位置/类型。
- [ReDef 作者仓库](https://github.com/waroad/ReDef)及[论文](https://arxiv.org/abs/2509.09192)：C/C++ 函数变更/revert 来源可作候选；任务/粒度和构建筛选不同，论文反事实实验提示编码模型可能依赖表面线索。作者的高置信度不能替代本项目金标/历史可见性认证，不执行其远端容器或 API 标注流程。

以上是方案依据和候选来源目录，本轮没有下载新数据/权重、运行上游代码或训练模型。实施门槛及批次见 [指导](../development/公开数据与语义模型衔接指南.md)、[当前规划](../development/后续整体规划与空间预算.md) 和 [评审记录](../reviews/2026-10-14-数据与预测路线复核及规划修订.md)。
