# 公开数据与历史评估口径

适用个人wang，2026-10-11。用户确认课程不指定数据来源，不限定单一团队、语言或私有项目；公开数据选型/构建由开发流程负责。产品目标与八模型要求保留，首批Apache Java研究数据不证明跨语言泛化。

## 修订原因与当前证据

第十三阶段实际3提交均Unknown，仅证明已有验收来源不足。生产 `time-labels-v1` 按真实clone/sync观测和证据发布时间审核；今天下载历史仓库不能自动获得历史训练截止时可用的标签，扩大下载量也不能解决口径不匹配。原“所有模型开发须等待数据合格”和“第十四阶段直接接A17～19”修订。

已下载Zenodo 5907002完整ApacheJIT与NeuroJIT固定revision日期表：106674行，28239外部buggy、78435外部clean，15个project字段组。提交键/标签/用途/year一一对应、无重复键；29136行author_date与日期表date不同，1314行year与author_date的UTC年不同。28239正例都有修复日期但均缺时区；在仅用于诊断的UTC假设下1例修复早于author_date，按衍生date则0例。不能猜测两种时间字段语义或静默改成一致。

原始数值12列加fix共13维，缺LT；Entropy最大6.5698556083，NDEV/NUC/SEXP有分数值，与本项目归一化Entropy、去重计数等语义不等价。不能仅重命名列冒充 `kamei14-dg-v1`。原FIX在真实历史特征中全缺失还揭示“确认时点”与预测输入可知性的设计问题，须单独核验/版本化，不能填0藏问题。

进一步只读抽查ActiveMQ提交ac5ba4082924fca214cf6f261d887fe3ebdffe23：GitHub原始author时间2013-10-03T14:49:45Z匹配ApacheJIT的1380811785，committer时间14:49:53Z匹配衍生date的1380811793。至少该样本差异是两个合法时钟，不能将全部29136差异称为损坏数据或自动丢弃；全量来源语义仍待核验。脱敏证据留本机clock-source-sample.json，不保存作者姓名邮箱。

14个project字段组按预声明author时间70/15/15切分后每区均有两类；apache/hadoop组全clean，保留拒绝，不合并同名Hadoop子项目掩盖问题。project字段组不自动等于独立仓库。类别齐全只是结构条件，不证明标签正确、样本量充分或评审效用。

## 三种合同与用途

| 合同 | 当前范围 | 明确边界 |
|---|---|---|
| 实际生产观测 time-labels-v1 / kamei14-dg-v1 | 第十三阶段已有内核/只读来源审计 | 实际观测/发布时间不回填；confirmed证据和完整覆盖；Unknown保留 |
| 外部发布标签基准 apachejit-published-13-v1 | 第十四阶段原始CSV/关联质量/分组切分审计 | 标签为作者发布的SZZ研究结果；不称人工确认、不称无缺陷事实；未训练或发布模型 |
| 离线历史回放 | 下一阶段独立设计/版本化 | 核验历史事件/Fix时间来源、标签延迟、负例观察覆盖/删失和预测时可知特征；不伪造系统观测 |

历史回放可以重建“当时可知的信息”，实际下载时间仍记录acquired_at。训练标签可用时间与评价标签收集时点分别声明，不通过全量未来标签训练过去的预测，不把最后时段尚未暴露的缺陷视为确定clean。不可把外部数据直接交给生产内核绕过门槛。

这不要求全部公开标签由用户人工确认。下一合同可使用明确来源/噪声/置信度且经抽检的SZZ弱监督银标，与人工复核金标分开记录和评价；由开发负责可核验来源和抽检。旧生产confirmed合同保留，新训练用途单独版本化；生产发布需兼容特征及有效评估，而不是无期限等待“完美标签”。

## 最新顺序与持续修订

第十四阶段公开数据审计 → 第十五阶段事件/Fix时间和十四维可知性/历史回放合同与真实小样本验证 → 数据集纵向接入及首条LR/RF链路 → 候选预测/风险评审 → 八模型受控比较 → 看板治理/最终验收。模型注册、任务/工件/指标工程可与数据适配并行；模型效果结论和生产发布必须满足相应用途的数据门槛。可单独做明确版本的外部基准实验，但不能发布到不兼容的产品特征链路。

遇到阻碍：记录实际证据 → 解释影响并告知用户 → 修订决策/整体规划/受影响规格/OpenSpec/追踪/指导 → 实现与验收 → 更新阶段报告和变更记录。历史报告保留当时事实，不重写为当前状态；根目录用户自建报告/PPT不自动编辑。个人进度不冒充团队审批，仍只推wang，确切SHA CI结果另留本机和聊天。
