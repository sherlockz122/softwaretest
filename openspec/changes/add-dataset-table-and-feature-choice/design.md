# Design: add-dataset-table-and-feature-choice

## Context

12 个数值特征（la、ld、nf、nd、ns、ent、ndev、age、nuc、aexp、arexp、asexp）在数据集构建时已经算好并存进每个成员行，但数据集详情页只显示仓库、提交、分区、标签四列；训练时这 12 个特征全部固定参与，形式由插件写死：逻辑回归内置 StandardScaler 管线，随机森林直接吃原始值。

想做特征对照实验（少用几个特征、给长尾计数特征取对数）没有入口。本 change 补两个能力：把数据以二维表亮出来，把特征选择权交给用户。

## Goals / Non-Goals

**Goals:**

- 数据集详情页按「一行一提交、一列一特征」的二维表展示全部 12 个特征，可过滤、可显隐。
- 训练请求可指定特征子集与每个特征的形式，缺省行为与现状逐位一致。
- 训练契约（特征、形式、标准化统计）随工件与报告密封记录，模型详情可查。

**Non-Goals:**

- 不动候选预测链路的 14 维特征合同，不改研究模型发布资格。
- 不做自动特征筛选、特征重要性排序。
- 数据集二维表不做排序与多条件组合查询。
- 不新增数据库迁移。

## Decisions

### 决策 1：特征与形式放进训练请求体，而不是新增数据库列

`features`/`forms` 是请求的一部分：入幂等键比较、写进任务负载与 `request.json`、随 `report.json` 回传校验。模型运行表本身不新增列，因为产物契约（报告 + 工件）已经承载了这两个字段，页面从报告读取即可，不需要为展示单独加列。

代价是「训练中」的运行详情看不到所选特征——可接受，训练中本来就没有产物可看。

### 决策 2：三种形式 raw / log1p / standardize，缺省随插件补全

`raw` 原始值、`log1p` 取对数（log(1+x)，适合 la、age 这类长尾计数）、`standardize` 标准化（z-score，均值方差只在训练分区拟合）。

缺省补全规则是「逻辑回归全标准化、随机森林全原始值」，正好是改动前两个插件的实际行为；这样所有旧请求、旧测试、旧产物语义不变。标准化统计只从训练分区拟合，验证与测试分区只用拟合结果——这是把「标准化」从 lr 专属管线拆成可选形式时不能丢的防泄漏纪律。

数值一致性要求：逻辑回归缺省配置下构造的矩阵必须与旧 StandardScaler 管线一致。sklearn 的 StandardScaler 用 ddof=0 的总体标准差、零方差列把 scale 置 1，实现时逐条对齐。

### 决策 3：feature_plan 归一化到固定顺序，校验集中在一处

用户给的 features 顺序随意，但训练矩阵的列序必须确定（幂等回放、产物对比都依赖确定性）。归一化规则：按数据集字段顺序（NUMERIC_FIELDS 的顺序）排列所选特征；forms 只允许出现已选特征的键，缺省的按插件补全。校验与归一化放 `policy.feature_plan()`，API 层与训练子进程共用，避免两处口径漂移。

### 决策 4：二维表展示全部由前端承担，后端只加过滤参数

成员行已经带着 numeric12 字段，二维表的渲染、列显隐、数值格式化都是前端的事；特征的人话命名按 PR #14 的口径集中放 terms.js，与 14 维特征的命名并排（同一概念共用措辞，如 LA=新增行数 对应 la 也是「新增行数」）。

后端只新增两个可选过滤参数（分区、标签），缺省不过滤——现有调用与测试的行为不变。

### 决策 5：effort（审查成本）始终用原始值的 la+ld

报告里的 effort 指标是「这次改动新增+删除的行数」，是物理量，不该随形式变化。load_partition 里在变换之前先算好 effort，后续形式怎么选都不影响它。

## Risks / Trade-offs

| 风险 / 权衡 | 说明 |
|---|---|
| 缺省配置的数值一致性 | 对齐 StandardScaler 的 ddof=0 与零方差处理；用「缺省配置下新旧矩阵逐元素一致」的测试锁住。 |
| 用户选择导致模型变差 | 特征越少、形式越偏，指标可能越差；报告照实记录，页面不承诺效果，只承诺复现。 |
| 变换后的矩阵不进 artifacts | 只记录契约与统计，不额外落一份变换矩阵，靠测试与产物密封保证可复现。 |
| 过滤参数语义 | 过滤只作用于成员查询，不动分区摘要与 CSV 下载，避免「页面过滤了、下载却全量」的误解。 |

## Validation

- 单元：feature_plan 的边界（空/重复/未知特征、非法形式、越权键）；变换矩阵的手算对照（log1p、z-score、零方差）；缺省配置与旧管线数值一致。
- 集成：真实 MySQL 上发起带特征选择的训练，产物与报告含契约字段；幂等重放与冲突路径。
- 前端：数据集页二维表渲染与列显隐、过滤参数；训练页默认状态、全不勾选禁提交、切换插件重置形式；模型详情契约展示。
- 契约检查与追踪矩阵更新后整体跑一遍。
