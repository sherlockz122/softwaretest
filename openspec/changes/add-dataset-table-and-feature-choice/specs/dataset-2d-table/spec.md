# Capability: dataset-2d-table

## ADDED Requirements

### Requirement: 数据集成员按二维表展示

数据集详情页 SHALL 以二维表展示就绪数据集的成员：每一行是一个提交，列 SHALL 包含仓库、提交、分区、标签与全部 12 个数值特征。

特征列的表头 MUST 使用界面术语表（terms.js）里的人话命名，并把原始代码（如 `la`）保留为悬停提示，方便对照日志与 CSV。数值 MUST 按口径格式化：绝对值小于 100 的值保留两位小数，其余按整数显示；非有限值 MUST 原样标出，不得静默吞掉。

未就绪的数据集 MUST 不展示成员表；表 MUST 支持横向滚动、窄屏可看全，分页行为与既有「数据样例」一致。

#### Scenario: 就绪数据集展示特征列

- **WHEN** 打开一个已就绪的数据集详情页
- **THEN** 成员表按「仓库、提交、分区、标签 + 12 个特征」的顺序显示列，特征表头是人话命名，悬停可见原始代码

#### Scenario: 未就绪数据集不展示成员表

- **WHEN** 数据集尚未生成完或任务失败
- **THEN** 页面不显示成员表，保留既有的未就绪提示与下载禁用逻辑

#### Scenario: 数值格式化口径一致

- **WHEN** 特征值为 213.0、0.42 这类普通有限值
- **THEN** 分别显示为 213 与 0.42；出现非有限值时该格显示占位符号而不是空白

#### Scenario: 分页与横向滚动保持可用

- **WHEN** 成员超过一页，或窗口宽度不足以显示全部特征列
- **THEN** 上一页/下一页与既有限制一致生效，表格区域可横向滚动且可被键盘聚焦

### Requirement: 特征列显隐与过滤

数据集详情页 SHALL 提供每个特征列的显隐开关，默认全部显示；取消勾选的列从表格隐藏，不改变分页、过滤与下载的数据。

成员查询接口 SHALL 接受可选的分区过滤与标签过滤参数，缺省为不过滤；过滤只缩小返回的成员集合，总数与分页 MUST 按过滤后的集合计算。

#### Scenario: 取消勾选隐藏特征列

- **WHEN** 用户取消勾选某个特征列
- **THEN** 该列立即从表格隐藏，其余列与分页保持不变，重新勾选后恢复

#### Scenario: 按分区过滤成员

- **WHEN** 查询成员时给出分区过滤参数
- **THEN** 只返回该分区的成员，分页总数按过滤后的集合计算，其他分区的行不出现

#### Scenario: 按标签过滤成员

- **WHEN** 查询成员时给出标签过滤参数
- **THEN** 只返回该标签的成员；分区与标签过滤同时给出时取交集

#### Scenario: 非法过滤参数被拒绝

- **WHEN** 过滤参数给出三个分区之外的值或非 0/1 的标签
- **THEN** 返回参数无效错误，不返回任何成员
