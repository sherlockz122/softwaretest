# 固定标签来源与覆盖审计

## Why
公开 CSV 的 buggy/clean 不能直接证明产品标签资格。AMQ 已发现发布修复并非原最早链接；其它项目尚未认证，clean 的筛选和观察覆盖也缺少独立证据。

## What Changes
- 固定 ApacheJIT 原始十四项目链接及筛选 notebook，验证字节、Git blob、取得时点；只读，不执行上游代码。
- 独立版本审计跨项目发布标签与原链接、时钟、候选重叠、修复选择及原始异常。
- 输出确定性分层复核清单与逐项未满足资格，不用事件时间代替知识时间，不自动把银标升为金标。
- 保留旧特征、标签合同和规模限制；本批不接 A17～19 或训练模型。来源审计与在线数据集按规划拆批。

## Impact
新增离线模块、脚本、合同测试和指导。无 API、数据库、依赖或生产资格变更。更新当前规划、遗留处置与阶段报告。

交付前远程wang已前进：快进保留其原型/配置等提交，修复引入的导入排序；不兼容的旧provision入口改明确拒绝并提示当前bootstrap，无账号写入，不自动转换旧配置。当前初始化合同不变，受影响检查及最终SHA CI重新验证。
