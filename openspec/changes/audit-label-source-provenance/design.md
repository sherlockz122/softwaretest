# 设计

固定修订 ddfd547ff8e3d3725f6a1fd0f177c0ebe085a4b5，目录表保留 project cohort 与 Git 仓库映射的区别。HDFS/MAPREDUCE 的真实仓库相同，但不合并统计；额外 hadoop 发布组无对应原链接，必须明确缺证。

下载器只允许固定 HTTPS raw URL，重定向仍受同一约束。精确大小/Git blob/SHA256 和不可变取得清单共同认证输入；仅存于项目 runtime，拒绝重解析点。完成清单可复用但不得重写首次取得时点。失败保留已验证源、清除本次 part；上游代码永不执行。

内核限制总输入100MiB、合计500000行、120秒；监督哈希和逐行循环，前后哈希拒绝输入漂移。原链接重复、时钟倒置及同 SHA 时钟冲突作为诊断而非擅自修正。发布键重复/结构畸形拒绝。原修复与最早链接分别统计，历史 available_at 为 null。完整负例覆盖、筛选重现、原生祖先、人工审查、十四维兼容分别记录不足。

每个项目/类别/链接状态取 SHA256 排序前两行，明确为可重复复核配额，不是概率抽样或噪声率估计。记录全链接摘要与最多八条展示链接，截断标志明确。不暴露源码、作者身份或运行配置。报告返回独立副本，内容绑定源、规则、取得时间；CLI 完成后发布，禁止覆盖输入或已有报告。

真实已有 AMQ 有限 Git 样本只读核对所见时钟和浅历史界限，不以其深度认证全项目完整负例。后续完整单头受控来源/抽检与兼容数据集另验收。

远程wang增量与本批无重叠，仅快进本地wang，保留远程提交。迁移/auth_support排序修正至原基线相同字节，生产规则不变；旧seed依赖已不存在，入口导入无副作用，main明确退出2而不是调用旧重置账号逻辑。正确bootstrap仍需显式凭据、保留已有账号。原型和新依赖元数据补做前端与新卷验收。
