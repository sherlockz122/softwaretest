# Design: add-model-pool-reuse

## Context

模型运行的产物（估计器 + 校准器 + 门槛 + 报告）已经密封存档。重复实验的浪费在于估计器拟合这一环节：同样插件、同样特征与形式、同样超参，在相似数据上重训出的估计器并没有质变。把「训练好的估计器」从某次运行里抽出来放进池子，后续训练只要特征合同对齐，就可以跳过拟合、直接在新数据集上重做标准化统计与校准——校准器与门槛本来就是逐数据集拟合的（防泄漏要求），所以复用不会破坏评估纪律。

## Goals / Non-Goals

**Goals:**

- 池中存放预置基线模型与已完成运行产出的估计器，训练时可指定或自动匹配复用。
- 复用训练跳过估计器拟合，但仍在新数据集上完成标准化统计、校准与定门槛；报告标注复用来源。
- 复用产物与从零训练产物同构，评估口径一致，可对比、可追溯。

**Non-Goals:**

- 不引入外部第三方模型；不做模型集成/蒸馏；不改候选发布资格规则。
- 池匹配不做「跨插件、跨特征集」的自动适配（特征集不一致的复用会静默改变语义，禁止）。

## Decisions

### 决策 1：池复用「估计器参数 + 训练契约」，校准与定门槛仍在新数据集上做

技术选型：池条目保存（插件、超参、特征合同、估计器参数）。复用训练 = 特征矩阵按新数据集拟合标准化 → 池估计器直接 predict_proba → 新数据集上拟合 sigmoid 校准器与定门槛。报告新增 `reused_from`（池条目 id + 来源运行/预置标签 + 训练契约），limitations 说明「估计器参数来自池，校准与门槛在本数据集上重做」。

备选路径：① 整条产物复用（校准器门槛一起复用）——门槛随数据分布漂移，直接复用等于把旧数据集的决策规则搬到新数据上，评估失真；② 池只存「初始化种子」让训练从同一随机起点开始——省不了拟合时间，只是可复现性，不解决「避免重新训练」。不采用。

### 决策 2：池条目只接受密封工件，注册与使用都要过契约校验

技术选型：池注册来源两种——预置基线（随代码发布的工件，在启动时注册）与已完成运行（用户把某次成功运行「加入池」）。注册时校验工件哈希、插件、特征合同完整性；复用时训练请求的特征集 MUST 与池条目的特征合同完全一致，不一致直接拒绝（`MODEL_POOL_CONTRACT_MISMATCH`）。

备选路径：① 池直接引用磁盘文件不做密封——工件被改、合同漂移都发现不了；② 特征集不一致时自动取交集适配——静默改变模型语义，拒绝更诚实。不采用。

### 决策 3：匹配规则固定为「同插件 + 同特征集 + 同特征形式 + 同超参」，不做模糊匹配

技术选型：训练请求可选 `reuse_from`（显式指定池条目 id）或 `reuse_policy: auto`（按四元组精确匹配，命中多个取最新，命中 0 个回退从零训练并提示）。显式指定的条目不匹配请求契约时报错，不回退。

备选路径：① 按插件 + 特征集的「相似度」打分匹配——相似度阈值没法定义，命中结果不可解释；② auto 匹配不到就报错——用户要的是「能省则省」，回退从零训练 + 明确提示更符合预期。不采用。

### 决策 4：预置基线池随代码版本走，用户池条目带归属与来源

技术选型：预置基线（LR/RF 在公开基准上的估计器）作为版本化工件随代码发布，启动时按版本注册，版本升级自动替换；用户加入池的条目记录来源运行、所有者、加入时间，可被本人（或 Admin）移除。池条目只读使用，不原地更新。

备选路径：① 预置模型上线时现训——启动变慢、训练环境与构建环境分离导致不可复现；② 池条目允许任意用户修改覆盖——审计链断裂。不采用。

### 决策 5：复用产物不享受发布捷径

技术选型：复用的模型运行在报告里带 `reused_from`，但发布资格、评估门槛与从零训练完全一致（评估本来就在新数据集上做）。产品链路感知不到「复用」差异。

备选路径：给池模型（尤其预置基线）直接开发布通道——绕过评估直接上产品线，违背「先评估后发布」的既有纪律。不采用。

## Risks / Trade-offs

| 风险 / 权衡 | 说明 |
|---|---|
| 估计器跨数据集分布漂移 | 校准器与门槛在新数据集重做，吸收分布差异；报告如实标注复用，用户可对比从零训练结果。 |
| 池工件被篡改 | 注册与复用双重哈希校验；与训练产物同一套密封机制。 |
| 特征合同不一致被静默复用 | 四元组精确匹配 + 显式指定时契约校验，不一致一律拒绝或回退。 |
| 池膨胀 | 用户条目可移除；预置基线只随版本更新，不叠加。 |

## Validation

- 单元：池注册校验（坏工件、合同缺失拒绝）、四元组匹配（命中/多命中/零命中回退）、显式指定契约不匹配报错、复用路径的报告字段。
- 集成：真实 MySQL 上从零训练 → 加入池 → 新数据集复用训练，断言估计器参数一致（同一工件哈希）、校准在新数据集重做、报告 reused_from 正确、风险列表与从零训练同构。
- 前端：训练页复用选择与回退提示、模型详情复用来源展示。
- 契约检查与追踪矩阵更新后整体跑一遍。
