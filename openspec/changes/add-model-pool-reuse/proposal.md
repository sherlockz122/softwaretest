# Change: add-model-pool-reuse

## Why

现在每次训练都从头拟合（LR 迭代、RF 建树），同一批数据做多组对照实验时反复重训同一插件模型。用户提出「可以考虑用一个现成模型放在池中使用避免重新训练」：把已训练好的模型（预训练基线或此前跑出的成品）放进模型池，特征与预处理对齐时直接复用估计器，只在新数据集上重做校准与定门槛——省掉重复训练，同时守住「不泄漏」的底线。

## What Changes

- 新增模型池：存放预置基线模型（LR/RF 在公开基准数据集上训练好的估计器）与用户已完成的模型运行。
- 训练请求新增可选 `reuse` 语义：指定复用池中某模型（或自动匹配「同插件 + 同特征集 + 同预处理」的池模型），复用其估计器参数，在新数据集上完成标准化统计拟合、校准与定门槛。
- 复用训练的报告 MUST 记录来源（池模型 id、训练特征合同、校验分数），与从零训练的产物同构可对比。
- 池中模型不可直接发布为候选产品：复用产物的评估仍在新数据集上完成，资格与从零训练一视同仁。

## Capabilities

### New Capabilities

- `model-pool-reuse`：模型池的注册、匹配与复用训练，复用产物的来源与评估可追溯。

### Modified Capabilities

- `model-training`（训练请求新增可选的复用来源；复用路径的报告结构扩展）。
- `model-evaluation`（复用产物的评估口径与从零训练一致，报告标注来源）。

## Impact

**数据库**

预估新增 `model_pool` 表（模型工件引用、插件、特征合同、来源数据集、注册时间）+ 迁移；或复用模型运行表加 pool 标记，待设计确认。

**后端**

池注册服务（工件密封、特征合同校验）、复用匹配（同插件 + 特征集 + 形式 + 超参）、训练入口分支（复用估计器，跳过拟合）、报告来源字段。

**前端**

训练页增加复用选择（「从模型池复用」或自动匹配提示）；模型详情展示复用来源与池模型信息。

**不在本次范围内**

不引入外部第三方预训练模型（JIT 领域无公认现成模型，先做「自己池里复用」）；不做模型自动组合/集成；不改发布资格规则。

**关联追踪**

受影响文档：docs/04（模型池接口与训练请求扩展）、docs/08（训练页与模型详情）、docs/07 新增 US-32（模型池复用）、PRD「模型训练与评估」需求域。

## 状态

本 change 已进入实施（2026-11-17）：模型池表与迁移、预置基线与运行入池注册、四元组匹配与复用训练路径、前端复用选择与来源展示全部落地，tasks 已按运行证据勾选。
