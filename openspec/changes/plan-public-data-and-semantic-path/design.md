# Context

当前为第十九阶段来源审计已交付的基线；公开数据专项保存/审计、Kamei/成熟度内核与可靠任务复用，数据集纵向及模型未交付。

# Decisions

PublicAsset负责原始清单/合法来源/适配/派生/重载，M3可选类型/位置，M4独立语义工件，M5用途与版本审计，M6冻结编码器/融合插件；复用权限/任务/原子发布，旧模型/轮次保持。原生14维、外部12数值、语义及函数/模块等粒度不能隐式混用。元数据字段和API仅拟定，实施前独立迁移/权限设计。

来源/复核记录和首条公共CSV资产为下一批有限纵切，不需一次所有来源变成gold；随后研究LR/RF工程、语义文本/冻结编码器和融合、候选目标域发布、八模型及语言/类型扩展。研究/历史/候选用途分门槛。未知保留，旧false不回写。

# Risks / Trade-offs

许可、噪声/删失、跨源重叠、粒度不符、无文本、预训练污染和捷径分别登记；现代模型不预先保证优于基线。只读硬件显示Intel Arc/约32GB RAM，未做训练探针，不因D约77.9GiB可用承诺全量微调。默认代码本地；模型权重/安全格式/版本/资源另审查，不能照搬上游pickle、容器或付费标注API。
