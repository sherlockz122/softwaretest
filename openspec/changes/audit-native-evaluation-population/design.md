Gap scope must follow evidence: an unreadable/unmapped file is a possible gap for every target in that fix's W interval; a concrete verified blame identity outside the fixed target frame is recorded as outside-frame and cannot be confused with an unmapped line. A concrete in-frame identity with invalid eligibility/time/ancestry affects that target. Preserve all original SZZ status/reasons/lines even where target-specific scope resolves an outside-frame case. Parse and verify a target on demand before giving it baseline-SZZ eligibility, never merely assert that metadata means parsed. A valid positive can remain provisional when other observations are missing; it still does not certify the earliest real defect or actual historical knowledge.

Before the full real observation phase, predeclare a label-blind small pilot by fixed SHA rank and measure the same implementation's Git/parser/SZZ time, sampled RSS and output. Pilot completeness is limited to its explicit units and cannot publish the full population. Exceeding budget stops expansion without moving roles. On POSIX, source Git children should share the supervised child session so cancellation/timeout can clean the owned group; Windows retains explicit owned-tree cleanup. Supervision is cooperative/sampled rather than an OS hard quota, and interruption tests must match the cleanup scope claimed.

Source and new execution bindings are captured before work and checked before immutable publication. New artifacts preserve full target membership, fixed roles, observation disposition, evidence hashes, gap intervals and reason counts. Interrupted or failed work retains attempts and explicit completed units; a resumed unit must verify its original bindings and hashes. Refuse drift/tampering rather than rewriting old results. Existing 1000-member replay/native feature contracts are not raised or bypassed: this is a source evidence audit, not native14 feature computation or a product dataset.
