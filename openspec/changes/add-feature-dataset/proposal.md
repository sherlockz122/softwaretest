# Why

第十阶段已有可审计 SZZ 候选证据，但还不能计算稳定的 Kamei14 输入或创建监督数据集。US-06～09 需要先固定公式、历史覆盖与信息可用时间，避免把缺失历史及事后标签填成零。

# What Changes

- 第十一阶段交付 US-06 计算内核及 US-07 质量统计前置，实际 Git 手算、时间/覆盖/重命名边界验收。
- 纠正 NUC 的歧义：统计相关文件上次修改提交的去重数量，而非全部历史修改次数。
- 后续切片接入固定接受快照、数据库、可靠任务、A15/A16 与页面；再实施成熟度、不可变数据集 A17～19、防泄漏和类别权重。
- 更新 docs/03、05～07、开发指导、规划、文档记录与阶段报告。

# Non-goals

本批不提供在线接口、特征数据库表、模型训练、语义 tokenizer 或监督标签。未知、候选 SZZ 和没有证据的提交不转为 clean。无 main 合并、团队故事 Done 或真实预测精度声明。
