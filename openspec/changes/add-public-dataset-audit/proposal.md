# Why

现有生产来源合同按本系统实际观测/发布时间审核，今天采集历史仓库不能自动证明历史训练截止时的标签可用性。真实3提交验收数据不足也不代表公开研究数据不可用。先验证公开数据与历史评估合同，避免继续纵向接入后才发现训练来源无法适配。

# What Changes

- 第十四阶段交付固定来源下载/完整性校验、只读公开CSV审计及按项目的历史时间切分可行性报告。
- 明确实际观测、外部发布标签基准、历史回放三种来源/用途；本批只交付外部发布标签基准审计，不伪造在线观测或宣布历史回放已合格。
- 核验发布时间、修复日期、特征语义、缺失与来源关系，报告阻碍与下一切片决策。
- 同步当前指导、规划、规格、追踪及阶段报告；模型工程可并行，真实效果与发布仍有数据门槛。

# Impact

新增离线审计模块/本机CLI和独立测试。无新依赖、数据库迁移、API/任务类型或页面功能新增；验收发现的Windows受控Git长路径兼容、移动端既有特征结果换行及只读存储统计一并修复，补相应指导/专项；不改 time-labels-v1 或 kamei14-dg-v1。数据/原始作者复现材料留D盘Git忽略runtime，仓库仅保存汇总及来源归属。仅wang。
