# Decisions

1. 下载仅固定Zenodo 5907002与固定NeuroJIT Git revision，保留原始CSV、许可/出处、实际acquired_at及SHA256。发布者MD5/Git blob SHA1用于核对发布一致性，SHA256用于本机内容身份；不执行复现包代码，不加载pickle模型。
2. 只读审计严格CSV schema、(project,commit_id)唯一性、布尔标签、UTC时间及有限非负数值；异源日期表必须匹配项目/SHA/标签/用途/year；不同事件时钟显式计数并待来源核验，不因合法author/committer差异直接拒绝，亦不静默改写。
3. apachejit-published-13-v1 原始12数值加fix共13维，不冒充本项目十四维。作者时间不冒充committer_time；缺LT及公式差异、fix输入可知性待核验。离线发布标签仅是外部SZZ研究标签，不是人工确认或无缺陷事实。
4. 每项目独立按author_date分组70/15/15切分，同事件组不跨集合，排序稳定；比例不按评估效果调整。两类/重复/缺失审计是结构可行性，不能推导生产发布可行性。没有修复日期的外部正例不得编造label_available_at，clean不得仅按年龄自动取得生产负标签。
5. acquisition_at是真实下载时间；external_fix_date只作来源报告。本批不对历史标签可用时间进行回填/拟合/训练，不将外部数据交给生产内核。后续历史回放单独定义修复时间重建、负标签观察覆盖与删失、特征在当时可知性、版本与源证据。
6. 报告不输出message/diff/原始身份；源文件有大小/行数/时限限制，默认读输入在runtime。CLI输出本机JSON，原始数据不提交。规划不足时先修正文档及解释阻碍，再实现。

# Verification

实际存储统计遇到测试临时目录枚举失败，修订只读测量返回显式完整性/未统计目录下界，DriveInfo余量仍独立测量。新增受控失败/重解析点统计验收，不改ACL或降低容量保护。

专项覆盖重复/日期缺失和冲突/无穷/NaN/非法布尔/同时间分组/单类/来源篡改/用途隔离/资源限制与确定性。真实完整CSV独立审计并保存汇总；保留首次失败。按现有全量后端、独立浏览器、严格OpenSpec、文档契约、确切SHA CI工作流验收。


全量回归另发现Windows Git深私有路径限制，采集spec/design先补子进程长路径合同；CloneExecutor Windows本机配置修复，保留旧安全边界/算法，新增深路径实测。最终需对新增生产兼容变更重建并完成全量/独立复验。

浏览器独立复验发现特征结果连续长文本撑宽390px页面至554px；修正列表换行并等待真实质量内容后验证页面无溢出、质量表内部滚动，失败尺寸及最终结果保留。本批无新页面功能。

后续真实pack补查发现：265字符文件Python普通stat报FileNotFoundError，旧容量扫描仅计288字节，不能认为长路径克隆成功即防护有效。受控回归第二轮在38%后主动中断并保留日志/原因，未声明全量通过。修复仅本地文件访问的Windows扩展路径，safe_path仍检查祖先重解析点，容量扫描计入长pack且不可读目录拒绝，UUID范围核验后扩展路径清理；Git子进程继续普通合法root。新增真实pack/发布/全目录字节一致性和不可读扫描测试，无注册表/PATH/ACL变更，最终重新重建/全量/独立验收。
