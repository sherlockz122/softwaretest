## Population and downstream contract
A label-blind metadata phase inventories full reachable graph/time bins, excluding old canonical+SHA memberships and reserved identities under explicit rules. Before decoding messages/classifying Fix/SZZ, seal the complete selected frame/roles/window/lag, technical scope and safety budgets; unsupported size refuses instead of dropping members. Default planned source frame follows existing2020-2025 role years and W90/L7 only if metadata feasibility fits; any adjustment is a new pre-label declaration, never a label/score-based search. Old roles and test remain untouched.

All-parent evidence must verify native commit/blobs/parents and complete projection, retaining unavailable objects, encoding/filter/clock/timeout gaps. Reuse reviewed current primitives only with explicit new-source binding; never monkeypatch the old ActiveMQ constants or rewrite old approvals. Cache adoption remains separately gated; default current source work without a new benchmark proof uses the supported uncached path.

Native14 readiness checks actual historic ancestry/causal feature inputs/limits and schema. Existing causal kernel rejects >1000 commits, >10000 file changes and >30 seconds, and unsupported merge ancestry may leave history features missing. These are real compatibility risks, not solved by selecting a new repo. This batch must report actual ready/refused rows and a complete gap worklist. Any needed scale or merge-history semantic revision requires an independent versioned implementation/probes before a qualified dataset/model can use it. Compatible dataset readiness must verify mature availability/purge, train-only boundaries, class/support and independent evaluation; no missing LT, Unknown or withheld role can be filled or reassigned.
