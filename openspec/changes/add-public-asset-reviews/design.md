# Design: add-public-asset-reviews

## Context

这次改动遵循 2026 年 10 月 14 日确定的公开数据与语义路线。首批只做 ApacheJIT 显式 CSV 这一种适配，其他 JSONL 来源、语言和类型的导入留到后续批次。派生出来的 JSONL 是可重载的原始记录加上 12 个数值视图，并不等同于已经创建好的训练数据集。

保存与复核都只在本机离线环境运行，存储根限定在 runtime 目录内。应用层的在线接口、用户身份和权限不属于本次范围，已有的能力保持原样，这里不重复实现。

## Goals / Non-Goals

**Goals:**

- 为第一条 ApacheJIT CSV 建立可重载的不可变资产，保留原始字节、取得与许可来源、适配器版本，以及 12 个数值的派生视图。
- 为 85 条定向复核包建立独立的不可变复核记录，把来源、资产、成员摘要和证据绑定在一起。
- 用有限的原生 Git 抽检验证可见的证据；对象或图不完整时，如实保留未知状态。

**Non-Goals:**

- 不做其他 JSONL 来源、语言和类型的导入。
- 不做在线数据集、应用权限和模型训练。
- 不把资产保存成功等同于训练数据集已经创建。
- 不认证复核里的陈述为真，也不做完整负例或金标认证。

## Decisions

### 决策 1：按内容寻址发布不可变资产

资产 ID 绑定来源清单、适配器与规则版本，以及原始文件和派生文件的摘要。写入时先在同一个磁盘上的临时目录里完整写满并校验，确认无误后再发布；遇到已有资产就重新载入，不覆盖，也不更新原来的取得时间。这样同一份内容始终得到同一个身份，重复导入和重载都不会改变原始记录。代价是每次导入都要完整校验一遍哈希。

### 决策 2：存储根与资源边界收在本机 runtime 内

存储根限定在 runtime 目录，路径拒绝链接和重解析点。总字节、行数、字段长度、合作式时限、取消和 D 盘容量都受控，清单记录来源事件口径、实际取得时间、原始 cohort（项目分组）与 canonical（规范）仓库，以及未知类型、语言的验证状态和能力不足的说明。未来重新适配会生成新的资产 ID，旧资产保留。这样离线资产不会越过受控目录，也不会把同一块盘写满；保留旧资产，是为了让引用它的复核记录仍然可读。

### 决策 3：复核记录是一条独立的不可变链

每条复核记录绑定审计报告的自哈希与来源、资产、复核包成员的原始摘要、revision 和前序哈希，并记录实际复核时间与证据状态。未审或未决的案件不会自动变成 clean（无缺陷）、buggy（有缺陷）、类型或 gold（金标）。证据文件只允许 runtime 目录下的有界 JSON，引用按哈希绑定。这样每一次复核都能追溯到当时依据的材料，后续只能往后追加，不能改写已经发布的记录。

### 决策 4：原生抽检在隔离环境里运行，缺证一律记为未知

原生探针使用一个禁网络、禁替换、禁 alternate（备用对象目录）的隔离 Git 环境，只读检查对象和祖先关系。缺少对象或者仓库是浅历史时返回 unknown（未知）；merge-base 退出码为 1 或 128、而图的完整性没有经过独立验证时，不能当作「不存在祖先」。这样做的理由是有限仓库覆盖不到全部对象，把缺证当成结论会制造假证据。

### 决策 5：本机操作者声明不冒充应用身份

本机命令行工具没有应用用户身份，记录里的 operator（操作人）只是本机复核声明，不代表已经实现基于角色的访问控制（RBAC）或授权认证。复核记录里的 verified provenance（已验证来源）只表示绑定校验通过，不认证陈述内容为真。源报告的 readiness（就绪状态）不回写，研究数据集与 A17～A19 留到下一批接入。这样离线切片不会借操作人字段制造越权印象，也不会把来源核对写成标签确认。

### 决策 6：失败与取消只影响本轮暂存

一次导入或复核发布失败、被取消或者超出容量时，系统只清理本轮自己的 UUID（通用唯一标识符）暂存内容，已经发布并通过校验的资产和复核记录保持不动。离线批次没有必要回滚到上一版，保留完整旧版本比回滚更安全；代价是失败尝试可能短暂占用磁盘，需要靠后续清理回收。

## Risks / Trade-offs

| 风险 / 权衡 | 说明 |
|---|---|
| 来源真实性 | 取得来源是否可信，依赖固定校验和来源清单；文件哈希不是数字签名。原始代码材料只封存，不执行。 |
| 磁盘占用 | 磁盘资产会比原始数据多出派生 JSONL 和临时副本，所以先按 1 GiB 预算，再根据实测处理。 |
| 合作式取消 | 旧的 public audit（公开数据审计）调用另有 60 秒上限，取消可能要等这次调用返回，不承诺硬实时。 |
| 定向 85 条 | 这是定向复核包，不是概率样本，不能用来估计总体噪声率。 |
| 本机复核声明 | operator 只是本机声明，不能当作独立专家证明或应用权限已经实现。 |

## Validation

- 专项验证合法的原始文件重载、派生结果和分页；输入、清单或输出发生漂移时，旧资产不被覆盖。
- 覆盖并发导入、失败清理、链接与越界路径、行数与字段长度、期限、取消和容量这些边界。
- 覆盖复核记录的来源、成员、前序、revision、UTC 时间和证据绑定，以及独立副本。
- 用真实的 106674 行发布 CSV 与原报告绑定做验收，并在本机已有的 AMQ 浅历史上做有限抽检。
- 完整回归覆盖已有后端与故障场景、前端和独立新卷，并复验存储保护。
