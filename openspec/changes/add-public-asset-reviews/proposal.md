# Change: add-public-asset-reviews

## Why

最新规划要求先交付公开资产的保存与重载，以及来源绑定复核。现有的 ApacheJIT 审计结果和 85 条定向复核包还不是可重载的资产，也不是不可变的复核记录，因此后续的数据集和模型工作缺少一个稳定、可追溯的输入。

如果这一步不做，公开数据就只能停留在一次性审计：同样的内容无法按固定身份重新载入，复核意见也没有地方保存当时的来源和证据。本批先完成一条有界的离线纵切，把资产保存和复核链立起来，在线数据集与模型留到后续批次接入。

## What Changes

- 支持第一条 ApacheJIT 的 CSV（逗号分隔值）格式适配。复用固定的取得清单，把原始字节、许可元数据和 12 个数值派生出的 JSONL（每行一条 JSON 的记录格式）保存为不可变资产，并提供重载校验、有限分页和离线目录。
- 建立独立的来源复核记录。每条记录绑定原报告、资产、复核包成员的摘要、revision（修订号）、实际复核时间和证据引用，并保留未决状态；复核不会改动原来的标签和资格。
- 做一次有界的原生缺陷与修复抽检，只读核验本机已有的 Apache ActiveMQ（AMQ）浅历史。缺少对象时保持未知状态，登记实际结果，而不是把它当作完整负例或金标认证。
- 补齐安全路径、容量、漂移、取消、原子发布、并发、篡改和可重载的专项测试，并用真实全表完成验收；同步更新相关文档和第二十阶段报告。

## Capabilities

### New Capabilities

- `public-asset-reviews`：公开资产的不可变保存与重载、来源绑定复核记录，以及有限的原生 Git 抽检。

### Modified Capabilities

没有。这次改动不改变任何已有能力的行为。

## Impact

**数据库**

不新增数据库表结构或迁移。资产、复核记录和证据都保存在 runtime 目录下的文件里，不进入应用数据库。

**后端**

不新增应用接口或依赖。交付物是本机操作者使用的命令行工具（CLI），它没有应用用户身份，也不代表已经实现基于角色的访问控制（RBAC）或在线权限。

**存储与资源**

资产、暂存副本和证据文件都只放在 runtime 目录内，路径拒绝链接和重解析点。磁盘先按 1 GiB 预留，再根据实测结果处理。原有的 v1/v2 合同、原始 CSV、原报告和用户材料保持不变；1000 个提交、10000 个文件、32 MiB 和 30 秒这些资源限制也保持原样。

**不在本次范围内**

这次不做在线数据集接入、在线资产上传、应用权限和模型训练。产品级的通用导入不在本次范围内，本批只覆盖本机离线的第一条 CSV 切片；其他 JSONL 来源、语言和类型的适配，以及研究数据集与 A17～A19 的接入，都留到后续批次。
