# Design

Same prior96 identities, order and train64/validation32 strata; no labels or scores used. Bind canonical v3, its660 v2 parent, fixed safe weights, selection and every executing source before reading and recheck before publication. Reconstruct v2/v3 text, coordinates and audits from exact Git blobs; no shallow/alternates/grafts. Preserve old limits/hashes.

For each hunk/role reconstruct all eligible physical LF lines. Candidate pool stays first32 exactly as v2/v3. Required class is maximum lexicographic tuple (base line inside nonempty old changed range, contains Unicode alphanumeric, nonblank); first component is0 for other roles and insertion-only base. A selected floor line only satisfies a group if it belongs to that required class. If class absent after cap, mark unsupported; never substitute cheaper empty lines. Symbol-only/whitespace-only changes retain their actual best available class.

Seed all v2 coordinates. In hunk order add lowest isolated-token-cost required-class whole line, coordinate ties, for each unsatisfied group; shared base lines may satisfy several hunks. Measure actual joinedBPE, not additive estimates. Above4032 or absent class retains proposed text, all identities and explicit unsupported reasons; this is failure of this algorithm, not proof no representation exists. Do not fill arbitrary extra lines to consume budget. Contiguous code windows cover all selected tokens: ceil(tokens/126), at most32; zero-role no jobs. Message preserves old2 windows, but any omissions mark unsupported. Audit eligible/capped/selected incidences, content-class, structural/lexical/changed-base counts separately; lexical proxies do not certify semantics or full-change coverage.

Only all-supported96 can encode. Safe local frozen CodeBERT CPUfloat32/threads4/batch8, existing masked/token-weighted pooling, dimension3076; new binding/version is not old-model compatible. Independent complete invocations differ in operation/processIDs yet match binding and every output byte; unsupported rejects before model/tokenizer loading. Arbitrary serving batch invariance remains untested.

Each supervised phase2700s/6GiB RSS, Git30s and original byte limits. Estimate contexts+encoding2GiB, independent backup3GiB, acceptance4GiB; measure D before each, controlled writes D. No large scans/backups during timed computation/fault regression. No download, classifier, oldtest or qualification promotion. Retain attempts/logs on failure; do not change policy after label/score inspection or rewrite manifests.
