# Agent辅助复核的证据分级与分阶段人工准入

## Why

用户提供两份agent辅助来源审核，允许先推进开发并要求保留后续专业审核安排。US-24/25来源用途分离、US-26语义/质量前置及NFR-02/05需要明确：工程可继续，独立人工认证不能凭回表布尔值或意见一致自动通过。

## What Changes

- 将本次回表登记为agent辅助外部意见，保留原件哈希及技术分歧，不改独立人工状态。
- 明确可先实施的工程/受限研究，以及来源认证、Gold/噪声率、依赖该来源的效用终验/发布之前必须补审的边界。
- 指定开发方补证责任、用户后续协调专业人员的触发点和失败退路；当前工程不等待人审。
- 同步数据规格/测试/追踪、规划/问题账/指导与交接，留存本机证据副本。

## Non-goals

不实现回表导入API/仲裁器、不改变已封存review链/标签/模型/readiness、不把AI一致当Gold、不扩大人口或运行训练/服务，不永久取消专业审核或允许先发布后补审。未来实现另立子change，不标记整个故事Done。
