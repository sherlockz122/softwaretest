# 方案与预算

采用仅探针使用的NativeReader子类，对每次command分类计数与包容wall计时；tick独立计数/计时，实际容量检查不省略；计时不被解释为纯进程创建成本。用psutil另线程按50ms采样自身及后代RSS，注明采样峰值下界/测量扰动，不与tracemalloc混同。分别登记plan、record、freeze_native_record、legacy/indexed/causal数值计算与输出摘要；DB查询/锁/原子冻结、完整Worker及语义读取器未由该探针覆盖，必须明确未测。

固定源acquisition封印、HEAD、canonical、取得时间；拒绝替换对象、浅库、alternates/grafts及路径重解析，不访问网络或执行仓库代码。先以plan按同一HEAD和规则封存成员（时钟/SHA排序），每次重规划必须相同；accepted HEAD/tree/blob核验维持原样。普通无缓存原生核验与既有v2缓存路径在同成员上交错至少3轮，各轮保留完整原生记录、输入及数值摘要精确对照；OS缓存不清、不称冷缓存。固定源为项目既有AMQ13def043，无新增克隆。

预声明夹具20/50/100与本地源20/50窗口，单次原生共享300秒、数值各30秒、整次CLI1800秒、采样RSS2GiB、输出64MiB，保留1000/10000/32MiB等既有更严格限制。前一窗口任次原生超过90秒或整批剩余预算不足时停止更大窗口，明确未测。计时不与构建/编码/故障测试/全树扫描并发；新增探针1/构建2/备份3/验收4GiB，实测D后执行。没有预承诺倍率，本批不批准提速方案；下批候选需同人口精确等价且重复中位至少20%改善、资源及跨平台监督清理通过，否则保留原实现。

旧解析器终止竞态使用fake子进程在最后poll时集中刷新stdout/stderr或越过deadline/撤销监督，先证明反例，再加退出且句柄关闭后的最终tick/deadline/双流上限检查；allow_limit仍返回None但stderr/时间不豁免。正常字节/状态/顺序及PARSER_VERSION不变，旧工件不重写。若parser源码改变，旧来源摘要与当前源码差异如实列为本批修复，不伪称旧执行绑定仍相同；下次新提取使用新来源摘要。
