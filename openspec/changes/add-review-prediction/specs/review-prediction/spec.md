# Spec Delta

## Purpose

让评审员对尚未合入的改动获得校准后的风险概率、影响因素和按风险排序的队列，作为安排审查顺序的依据，不代替合并决策。

## ADDED Requirements

### Requirement: 候选预测

系统 SHALL 对给定仓库、基准点和待评审的引用或改动内容计算候选特征，用已注册的模型给出校准后的风险概率。历史特征的计算 MUST 严格截止到基准点时点，不使用基准点之后才出现的信息；候选预测中的修复标记按 0 处理并在结果中说明原因。输出 SHALL 携带校准概率、风险等级、审查成本、模型版本、特征版本和判定阈值，其中风险等级 MUST 依据校准概率与判定阈值按声明的口径划分。

#### Scenario: 有效引用返回校准概率

- **WHEN** 评审员对合法仓库提交基准点和可解析的候选引用，且指定模型已注册并带有校准器和判定阈值
- **THEN** 系统返回校准后的风险概率、风险等级、审查成本和主要影响因素
- **AND** 响应携带模型版本、特征版本和判定阈值，结果可以追溯到输入摘要

#### Scenario: 直接提交改动内容

- **WHEN** 评审员不给出候选引用，而是直接提交待评审的改动内容
- **THEN** 系统按同样的口径计算特征并返回预测结果，不要求必须存在远端引用

#### Scenario: 计算超过同步时限转为任务查询

- **WHEN** 候选预测的计算时间超过同步返回的时限
- **THEN** 接口先返回任务编号，评审员通过任务页面查询最终结果

#### Scenario: 候选引用不存在

- **WHEN** 提交的候选引用在仓库中不存在或无法解析
- **THEN** 系统返回明确的引用无效错误，不产生预测结果

#### Scenario: 基准点不可达

- **WHEN** 提交的基准点在仓库中不可达
- **THEN** 系统返回明确的基准点错误并说明原因

#### Scenario: 改动超出输入限制

- **WHEN** 待评审改动的内容超过系统声明的行数或文件数限制
- **THEN** 系统在计算前拒绝请求，并在错误信息中说明当前限制

#### Scenario: 模型不具备预测资格

- **WHEN** 指定的模型运行未注册、缺少校准器或判定阈值，或者特征版本与模型训练时不一致
- **THEN** 系统拒绝预测，并说明模型不满足预测条件的具体原因

### Requirement: 预测解释

系统 SHALL 为已有预测结果提供解释，返回每个因素的名称、原始值、贡献值和影响方向。解释 MUST 同时说明这是相关性排序的结果，不代表缺陷的因果根因。

#### Scenario: 查询预测解释

- **WHEN** 评审员对一条已有预测结果请求解释
- **THEN** 系统返回各影响因素的名称、原始值、贡献值和影响方向
- **AND** 响应明确说明结果是相关性排序，不代表因果根因

#### Scenario: 预测结果不存在或无权查看

- **WHEN** 评审员请求解释的预测结果不存在，或者不属于其可查看的范围
- **THEN** 系统返回明确的未找到或无权访问错误

### Requirement: 风险队列

系统 SHALL 把批量预测的结果组织成默认按校准概率降序排列的风险队列，概率并列时按事件时间和提交标识升序稳定排序。队列 SHALL 显示每项的审查成本，风险密度只作为辅助字段。超大改动 MUST 显著标识，不得因为风险密度低而被隐藏。

#### Scenario: 默认排序与稳定并列

- **WHEN** 评审员查询一次批量预测的结果队列
- **THEN** 队列按校准概率降序排列，概率相同的项按事件时间和提交标识升序稳定排列
- **AND** 每项同时显示审查成本和风险密度两个字段

#### Scenario: 超大改动显著标识

- **WHEN** 队列中存在审查成本超过声明阈值的改动，即使其风险密度很低
- **THEN** 系统对该项给出显著标识，并且该项保持在队列中的可见位置

#### Scenario: 队列为空

- **WHEN** 批量预测没有产生任何结果
- **THEN** 系统返回明确的空队列状态，而不是无法区分的空响应

### Requirement: 批量预测任务

系统 SHALL 支持创建批量预测任务，用数量或时间窗限定扫描范围。任务 SHALL 支持协作式取消和同根重试，结果导出 MUST 携带所用模型和统计口径。

#### Scenario: 创建限定范围的批量任务

- **WHEN** 评审员用数量或时间窗限定范围后创建批量预测任务
- **THEN** 系统受理请求并返回任务编号，任务完成后结果可以通过队列接口查询

#### Scenario: 范围超限在入队前拒绝

- **WHEN** 请求的扫描范围超过系统声明的数量或时间窗上限
- **THEN** 系统在任务入队前拒绝请求，并说明当前上限

#### Scenario: 取消批量预测任务

- **WHEN** 评审员请求取消正在执行的批量预测任务
- **THEN** 任务在下一个安全检查点停止，不留下写了一半的结果数据

#### Scenario: 重试失败的批量预测任务

- **WHEN** 评审员对失败的批量预测任务发起重试
- **THEN** 系统创建新的任务运行，并保留它与原任务的派生关系

#### Scenario: 导出结果携带模型和口径

- **WHEN** 评审员导出批量预测的结果
- **THEN** 导出内容包含所用模型的标识、判定阈值和排序口径

### Requirement: 隔离与安全边界

系统 MUST 在隔离的临时工作区中处理待评审的改动，用户传入的引用和内容不得被当作命令执行，仓库中的脚本也不得被执行。

#### Scenario: 可疑引用不触发命令执行

- **WHEN** 待评审的引用包含命令片段、特殊字符或指向工作区之外的路径
- **THEN** 系统只把它当作普通字符串校验，或者返回明确的引用无效错误
- **AND** 不发生任何命令执行或工作区之外的写入

### Requirement: 预测结果可追溯

每次预测 MUST 保存输入摘要、模型运行标识、特征版本、判定阈值和输出结果，使任何一条结果都能追溯到产生它的模型、特征口径和输入。

#### Scenario: 从结果追溯到模型和输入

- **WHEN** 评审员查看一条预测结果或它的解释
- **THEN** 系统展示产生该结果的模型运行标识、特征版本和判定阈值
- **AND** 输入摘要可供后续审计核对
