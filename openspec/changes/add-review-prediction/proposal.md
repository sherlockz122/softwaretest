# Change: add-review-prediction

## Why

课程硬指标「概率和解释」与「风险列表」对应 US-16～US-19，目前只有设计、API 编号和计划测试，没有任何实现，合入前评审链路在系统里是断的。第二十二阶段已经验收了带校准器和阈值的 LR/RF 研究模型，可以作为第一个候选预测引擎；现在补上预测这一段，把「数据、特征、模型、预测、解释、风险队列」整条链路闭合，Sprint 2 的演示和课程验收才有落点。

## What Changes

- 新增候选预测：给定仓库、基准点和待评审的引用或改动内容，系统计算候选特征，用已注册的 LR/RF 研究模型给出校准后的风险概率。
- 新增预测解释：返回模型版本、判定阈值、各特征的原始值、贡献值和影响方向，并说明这是相关性排序而不是因果结论。
- 新增风险队列：批量预测结果默认按校准概率排序，带审查成本和风险密度两个辅助字段，超大改动显著标识。
- 新增批量预测任务：按数量或时间窗限定扫描范围，可取消、可重试，直接复用已验收的异步任务能力。
- 新增数据库迁移，建立预测任务和预测结果两张表，对应产品设计文档 M7 模块的规划。
- 新增候选预测、预测解释和风险队列三个页面，对应低保真原型的相应屏幕。

## Non-goals

不实现模型发布（A22），预测直接引用已注册的研究模型运行，发布和比较能力由 add-model-evaluation 负责。不训练任何新模型，不引入语义输入，预测只使用已验收的 LR/RF 研究模型。不实现趋势看板、任务中心等 US-20 及以后的能力。不改变应用基础能力的任何行为契约，异步任务直接复用。系统只给出风险排序依据，不判断某次改动一定产生缺陷，也不自动决定合并与否。

## Capabilities

### New Capabilities

- `review-prediction`: 候选预测、预测解释、风险队列和批量预测的行为契约，对应 A24～A27。

### Modified Capabilities

无。

## Impact

- 数据库：新增迁移建立预测任务和预测结果两张表，沿用已有的异步任务表，不改动 0001～0011 已交付的结构。
- 后端：预测模块实现 A24～A27，复用已验收的特征计算内核、异步任务接口和模型工件读取。
- 存储资源：预测不训练，模型工件只读挂载，不增加磁盘预算。
- 不在范围内：模型发布（A22）、趋势看板、语义输入和其余六个模型的扩展。
- 关联追踪：US-16～US-19、A24～A27、基线 DG-BL-2026-09-26；受影响文档包括 [产品设计文档](../../../docs/02-产品设计文档.md)、[数据与算法规格](../../../docs/03-数据与算法规格.md)、[API 与数据库规格](../../../docs/04-API与数据库规格.md)、[测试与验收计划](../../../docs/05-测试与验收计划.md)、[界面与交互规格](../../../docs/08-界面与交互规格.md) 和 [需求设计测试追踪矩阵](../../../docs/07-需求设计测试追踪矩阵.md)。
