## ADDED Requirements

### Requirement: 修复参考检索
系统 **SHALL** 针对指定提交，从同一仓库的历史修复提交中检索相似修复，按相似度降序返回，每条参考 **SHALL** 说明相似理由。相似度 **MUST** 由触及文件的重叠数量、十四维特征的距离和修复证据等级共同决定。返回的参考 **MUST** 全部来自该仓库真实存在过的修复提交。检索范围 **SHALL** 覆盖该仓库已采集的全部历史，包括时间上晚于目标提交的修复，因为修复参考是检索材料，不参与模型训练。

#### Scenario: 正常返回相似修复
- **WHEN** 目标提交在该仓库中存在，并且仓库历史里有与它触及相同文件或特征相近的修复提交
- **THEN** 系统返回按相似度降序排列的修复参考列表
- **AND** 每条参考携带修复提交编号、提交信息摘要、触及文件、修复证据等级和相似理由

#### Scenario: 相似度较低时如实标注
- **WHEN** 仓库历史里有修复提交，但没有任何一条与目标提交触及相同文件，特征距离也较远
- **THEN** 系统返回这些修复提交并明确标注相似度低
- **AND** 系统不把它们描述为与目标缺陷同类

#### Scenario: 仓库没有修复历史
- **WHEN** 仓库历史里不存在任何修复提交
- **THEN** 系统返回明确的空状态，说明该仓库尚无修复历史
- **AND** 系统不返回其他仓库的数据，也不伪造参考

#### Scenario: 目标提交不存在
- **WHEN** 请求指定的提交编号在该仓库中不存在或不可达
- **THEN** 系统返回明确的提交错误码并说明原因

### Requirement: 修复参考的输入边界
候选预测链路的修复参考 **MUST** 使用与预测相同的目标改动作为检索对象。查询结果数量 **SHALL** 受限额约束，超出限额的部分不返回，响应中说明总数与上限。检索 **SHALL** 只使用本地已存储的数据，不发起外部网络请求。

#### Scenario: 检索对象与预测一致
- **WHEN** 用户在候选预测结果页查看同类修复参考
- **THEN** 系统针对与这次预测相同的改动进行检索
- **AND** 检索范围与预测使用的基础点和候选改动一致

#### Scenario: 结果超过限额
- **WHEN** 匹配到的相似修复数量超过声明的上限
- **THEN** 系统只返回限额内的条目，并在响应中说明匹配总数与返回上限

### Requirement: 修复参考的权限与可追溯
修复参考接口 **SHALL** 走现有的登录校验与只读权限，未登录请求 **MUST** 被拒绝。每条参考 **SHALL** 能链接到对应的修复提交详情和修复证据记录，接口响应 **SHALL** 携带本次检索使用的修复证据规则版本号。修复参考页面 **MUST** 说明这些参考来自历史记录，是同类缺陷的修法示例，不是对当前缺陷的根因结论。

#### Scenario: 只读角色可以查看
- **WHEN** 具有只读权限的用户请求修复参考
- **THEN** 系统返回检索结果
- **AND** 接口不产生任何写入

#### Scenario: 未登录请求被拒绝
- **WHEN** 请求没有携带有效登录凭据
- **THEN** 系统返回认证错误，不执行检索

#### Scenario: 参考可以追溯到证据
- **WHEN** 用户查看一条修复参考
- **THEN** 页面提供进入该修复提交详情和修复证据记录的入口
- **AND** 响应携带本次检索使用的修复证据规则版本号
