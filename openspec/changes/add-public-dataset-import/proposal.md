# Change: add-public-dataset-import

## Why

现在能进产品的公开数据只有一种：运维用专项脚本把 ApacheJIT 下载、审计、封装进资产库，用户在数据集页挑那份资产。手里另有一份按提交粒度的逗号分隔值（CSV）时，没有入口把它变成资产，也就建不了数据集。

十七项改进里的「可加载已有公开数据集」指的就是这个入口：页面上传、显式说明每列是什么、服务端体检通过后封装成不可变资产。

## What Changes

- 新增导入接口：接收上传的 CSV 文本、显式列映射与来源声明，在服务端完成结构与口径检查后封装成不可变资产，返回资产标识与来源摘要。
- 新增页面表单：选文件、填列映射、提交、看结果；失败时显示错误码与缺哪一列，不显示半份结果。
- 资产按来源种类分开版本：下载来源与上传来源各用自己的适配器版本与文件清单，读旧资产的行为保持不变。
- 上传来源不走 ApacheJIT 的许可常量，改为要求调用方显式声明许可与来源，缺失即拒绝。
- 列映射必填十六列：提交编号、项目、标签、作者时间与十二个数值特征；缺任一列明确拒绝，不补零也不猜列。

## Capabilities

### New Capabilities

- `public-dataset-import`：把上传的提交级 CSV 按显式列映射封装成不可变资产，并在封装前完成结构、键、数值、时间与来源声明五项体检。

### Modified Capabilities

无。数据集创建、训练链路与既有资产内容都不变。

## Impact

- 新增接口：`POST /api/v1/public-assets`（导入），接口清单从 36 条增到 37 条，OpenAPI 基线要重新导出。
- 受影响的前端：数据集页增加导入面板；新增组件测试。
- 受影响的本目录文档：`docs/03-数据与算法规格.md` 的公开数据口径、`docs/04-API与数据库规格.md` 的接口清单、`docs/05-测试与验收计划.md` 的数据集验收条目、`docs/07-需求设计测试追踪矩阵.md` 的 US-08 行。
- 关联用户故事：US-08（不可变数据集）、US-09（分区与标签）；对应十七项改进里的「可加载已有公开数据集」。
- 非目标：不做服务端出网下载；不接收压缩包；不支持缺少数值特征的行，缺特征要等数据管线支持缺失值后再做；不做断点续传与导入任务队列，导入在请求内同步完成并有行数与体积上限。
