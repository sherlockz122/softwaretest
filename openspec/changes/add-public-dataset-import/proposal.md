# Change: add-public-dataset-import

## Why

现在数据集只能从系统内置的公开资产（apachejit 上游源）构建，用户自己的 CSV/JSONL 缺陷数据（比如其他课程作业或导师给的标注文件）进不了系统，只能改代码接管道。用户要求「可以加载已有的公开数据集」：把一份外部已有数据文件上传（或指定本地路径），系统按约定的列格式归一化、校验、切分，走与内置资产完全相同的构建、下载、训练链路。

## What Changes

- 新增公开数据集导入入口：用户提交一个 CSV/JSONL 文件（上传或服务器本地路径），声明其列映射与许可。
- 导入走「清单 + 内容哈希 + 密封」的既有资产管线：文件先归一化成 normalized 记录（仓库、提交、时间、标签 + 12 个数值特征），再做去重、切分、入库——与内置资产同一套审计与防漂移机制。
- 身份列（仓库、提交、事件时间、标签）与 12 个数值特征列在 v1 全部必填，缺列拒绝并列出缺口；fix 列可选，缺的按「未提供」带原因（与 lt 缺失同一口径）。数值特征部分缺失的容忍列入不在本次范围（需贯通训练矩阵契约，另立 change）。
- 内置的 Kamei 十四维公开数据集（apachejit）保持为「预置公开资产」，与新导入通道并列展示。

## Capabilities

### New Capabilities

- `public-dataset-import`：外部 CSV/JSONL 缺陷数据的导入、归一化与入库，走与内置资产一致的质量审计。

### Modified Capabilities

- `dataset-detail`（数据集摘要记录 `source_kind`：内置资产 / 导入文件，详情页展示来源与列映射）。
- `dataset-split-choice`（导入数据集同样适用比例自选与验证集可选）。

## Impact

**数据库**

不需要新表：导入元数据（许可声明、列映射）随资产 acquisition 密封并进入数据集摘要，存储复用资产目录结构。

**后端**

新增导入服务（文件校验、列映射解析、归一化批处理、防漂移），复用 `research_dataset.prepare` 的切分与 dataset_service 的批次入库。

**前端**

数据集列表新增「导入数据」入口（文件上传或路径填写 + 列映射预览 + 标签口径说明），详情页展示来源与映射。

**不在本次范围内**

不做在线 URL 抓取；不自动推断列语义（用户必须声明映射，避免猜错标签列）；不承诺任意格式（只收 CSV/JSONL 且列名必须可映射）；v1 不支持数值特征列部分缺失的导入（缺列拒绝并列出缺口，缺失特征容忍另立 change）。

**关联追踪**

受影响文档：docs/04（导入接口与数据库）、docs/08（导入界面）、docs/07 新增 US-31（加载已有公开数据集）、PRD「数据集」需求域。

## 状态

本 change 已进入实施（2026-11-13）：proposal/design/specs 按 v1 实际范围修订（数值特征列齐全、fix 可选），tasks 带验证环节与具体验证步骤，实现与勾选随本批次推进。
