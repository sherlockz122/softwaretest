## ADDED Requirements

### Requirement: 上传导入契约

系统 SHALL 提供导入接口，接收一份提交粒度的逗号分隔值（CSV）文本、十六列显式映射与来源声明，体检通过后封装成不可变资产。

映射 MUST 覆盖十六个必填字段：提交编号、项目、标签、作者时间与十二个数值特征。缺失任一字段时 MUST 拒绝并列出缺失字段名，不得补默认值。

#### Scenario: 正常导入

- **WHEN** 上传一份列齐、数值有限非负、标签只取两值的 CSV，并给出十六列映射
- **THEN** 返回资产标识、来源摘要、行数与标签分布

#### Scenario: 缺少必填列

- **WHEN** 映射未覆盖十二个数值特征中的一列
- **THEN** 返回明确错误并列出缺失的字段名，不写任何资产

#### Scenario: 标签或数值非法

- **WHEN** 标签列出现第三类取值，或数值列为空、非有限、为负
- **THEN** 导入失败并指出首个不合规行的行号

#### Scenario: 超过行数或体积上限

- **WHEN** 文本超过四兆字节或行数超过两万
- **THEN** 导入在解析前被拒绝，返回对应错误码

### Requirement: 来源种类与版本分开

资产清单 MUST 记录来源种类与对应的适配器版本。上传来源与下载来源 MUST 各用各的文件清单与版本号，读取旧资产的行为不得改变。

#### Scenario: 读旧资产

- **WHEN** 读取一份改动前封装好的 ApacheJIT 资产
- **THEN** 校验通过，清单内容与改动前一致

#### Scenario: 版本与文件清单不匹配

- **WHEN** 清单声明的版本与文件清单不属于同一来源种类
- **THEN** 读取失败并指出不匹配的字段

### Requirement: 资产不可变与幂等

资产 MUST 以内容寻址目录存放，封装完成后不得原地改写。

相同内容与相同声明的重复导入 MUST 得到同一资产标识，或明确说明该资产已存在。

#### Scenario: 重复导入

- **WHEN** 用同一份 CSV 与同一份声明再次导入
- **THEN** 返回与首次相同的资产标识，已存在资产的内容不被改写

#### Scenario: 声明不同内容相同

- **WHEN** 内容相同但许可声明不同
- **THEN** 生成新的资产标识，两个资产各自可追溯

### Requirement: 导入权限与来源声明

导入 MUST 只允许管理员与成员角色执行，只读角色 MUST 被拒绝。

导入 MUST 要求调用方显式声明许可，取值必须在允许集合内；声明缺失或取值不在集合内时 MUST 拒绝。

#### Scenario: 只读角色导入

- **WHEN** 只读角色调用导入接口
- **THEN** 返回权限不足错误，不进行解析

#### Scenario: 许可缺失

- **WHEN** 请求未给出许可或给出不在允许集合内的取值
- **THEN** 返回明确错误，不写资产

### Requirement: 页面导入表单

数据集页 SHALL 提供导入面板：选择文件、填写许可与十六个映射、提交，并在结果区显示资产标识与行数。

失败时 MUST 显示错误码与可行动说明（例如缺哪一列），不得显示半份结果。

#### Scenario: 表单提交成功

- **WHEN** 在页面选好文件并填完映射后提交
- **THEN** 结果区显示资产标识、行数与标签分布，资产可被后续数据集创建引用

#### Scenario: 表单提交失败

- **WHEN** 映射缺列或文件无法解析
- **THEN** 错误区显示错误码与缺失列名，表单内容保留以便修改
