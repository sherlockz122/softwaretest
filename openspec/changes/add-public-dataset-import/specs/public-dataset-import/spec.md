# Capability: public-dataset-import

## ADDED Requirements

### Requirement: 导入 CSV/JSONL 缺陷数据集

系统 SHALL 接受用户提交的外部 CSV/JSONL 缺陷数据集（multipart 上传或服务器本地路径，本地路径仅管理员），走与内置资产相同的归一化、密封与审计管线。导入请求 MUST 携带显式列映射：canonical_repository、commit_id、事件时间、label 四个身份列为必填，其余列可映射到已知数值特征名；MUST NOT 自动推断列语义。

#### Scenario: 声明列映射导入文件

- **WHEN** 用户提交文件与合法列映射
- **THEN** 系统归一化文件、生成清单与内容哈希并密封，导入任务创建成功

#### Scenario: 身份列缺失或映射非法被拒绝

- **WHEN** 列映射缺少任一身份列、映射到未知特征名或重复映射同一列
- **THEN** 返回参数无效错误，不创建任务

#### Scenario: 同文件同映射幂等

- **WHEN** 以相同文件与相同列映射重复提交
- **THEN** 返回同一个任务，不重复导入；更换列映射则视为新请求

### Requirement: 特征列缺失按未提供处理

外部数据集的特征列 SHALL 允许部分缺失：未映射的数值特征在成员行中为 null 并带缺失原因，摘要 limitations MUST 记录缺失特征清单；导入 MUST NOT 因为特征列不全而拒绝。缺失特征 MUST NOT 参与训练特征列表。

#### Scenario: 只带部分特征列的文件可导入

- **WHEN** 文件只有身份列与部分特征列
- **THEN** 导入成功，缺失特征的成员行按「未提供」展示，摘要记录缺失清单

#### Scenario: 缺失特征不进训练

- **WHEN** 训练基于导入的数据集
- **THEN** 可选特征不包含缺失的特征，训练契约只含实际参与的特征

### Requirement: 来源可追溯

数据集摘要 SHALL 记录 `source_kind`（内置资产 / 导入文件）与导入来源描述（文件名、内容哈希、列映射摘要）；数据集详情页 SHALL 展示来源与映射。导入文件的漂移防护 MUST 与内置资产一致：文件改动后重跑构建以漂移错误失败。

#### Scenario: 详情页展示来源

- **WHEN** 查看导入数据集的详情
- **THEN** 页面显示来源类型、文件名与列映射摘要

#### Scenario: 导入文件被改动后拒绝

- **WHEN** 密封后的导入文件内容被修改，再以原哈希发起构建
- **THEN** 构建以源漂移错误失败，不产生不一致数据
