# Design

## 当前事实和决策

基线wang319d676。原生reader逐对象/逐文件调用仍存在，在线v2已有attempt内8MiB/512条blob缓存和100提交字段投影；离线causal探针未启用该缓存。记录对方测量为未独立复现，不将100条探针与12600条纯内核相除作为线上归因。

本change交付计划。第十八阶段暂不使用常驻cat-file的选择不被就地推翻；后续同口径量测后可另立实施子change验证batch。文件/身份/时间因果/模式/原生核验/摘要/租约和原子冻结约束保持，旧规则漂移仍拒绝。任何输出语义变化另立版本。

## 量测与资源

固定项目SHA/依赖/Git/解释器、硬件、bare HEAD/取得时间/canonical/成员摘要/覆盖；分别测解析、在线v1/v2、离线探针、纯内核和DB冻结。统计命令类别、监督与容量查询、缓存、锁时间、wall及进程树RSS；Python分配峰值单列。先20/50/100窗口和真实Git边界夹具，预算允许才至200，至少3次可比重复并报告全部运行/中位/范围，不把未控制的OS缓存称冷缓存。

开工另声明收益/退化门槛、单次和整批时限、预计D/RSS峰值及停止条件；沿用包装器ExpectedGrowthGiB，无新下载/无界全仓默认。计时、编码和故障回归不并发全树扫描，资源不足保留结果并停止，不转C。

## 安全和恢复验收

未来batch设计覆盖类型/长度/缺对象/截断错位/超限/stderr/管道阻塞、退出后最终检查、取消/失租/截止/父进程终止和Windows/Linux子进程清理；命中缓存仍监督。等待和容量检查按时间/增长界限设计，不能直接阻塞wait或无证明固定64次。

保留accepted HEAD/private快照、完整原生DB对比、模式、rename/merge、输出界限和一次原子冻结，Git/CPU在锁外。旧实现为等价基准，但已知缺陷不得因追求等价豁免；语义修复另版本。比较记录/摘要/冻结输入/向量/原因/质量与故障恢复；子change失败或无收益保留原实现。

## 路线和退出

扩大原生输入前完成相关量测；冻结研究资产和第二十四阶段准入路线按各自资格继续。索引退化不凭小幅内存差认定GC/字典原因，另查DAG/作者衰减/dense回退。采集性能不代替预测/列表P95、来源/许可/Gold、模型效用或NFR05字节确定性认证。

实施子change须关联US-01/02/06/07及测试计划，记录失败/负结果、范围和版本兼容，按现行本机/确切SHA CI工作流交付；本规划未执行这些未来任务。
