# 原生Git读取性能反馈的选择性采纳与验证计划

## Why

US-01/02解析与可靠任务、US-06/07特征及NFR-02/03/05仍受逐提交Git读取成本约束。10月19日组员反馈指出合理热点，但项目版本、原始计时和内核脚本尚未对齐，部分倍率/容量结论不能直接成为产品参数。

## What Changes

- 建立同版本、同源成员、分阶段且可重复的量测与安全验收计划。
- 将batch对象读取、监督等待和容量检查优化列为有条件候选；收益非单调单独复测。
- 明确第十八阶段暂不采用常驻进程的历史范围和后续变更条件；保留全部现行保护和研究/产品门槛。
- 同步决策、指导、整体规划、遗留、追踪和更新记录；本轮仅文档采纳，不修改实现。

## Non-goals

不执行性能压测、改运行参数/接口/schema/依赖，不直接引入常驻进程或改变旧v1，不扩大规模、不承诺速度、不重写工件/标签、不改变语义路线或标记故事Done。未来实现须另立子change及实际预算。
