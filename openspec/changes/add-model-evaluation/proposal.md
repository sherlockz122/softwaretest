# Change: add-model-evaluation

## Why

项目已经有固定的公开研究数据集，共十二个数值列，但还没有一条真正跑通的训练、评估和模型工件应用链路。没有这条链路，US-09、US-11～US-15 就拿不到可复现的训练结果，研究结论也无法与候选发布资格分开。

## What Changes

- 新增编号 0011 的数据库迁移，用于模型运行和模型工件；新增名为 model.train 的可靠训练任务，并让训练在受监督的 CPU 子进程中执行。
- 补齐 A20、A21、A23 对应的训练、详情、插件和运行目录能力；A22 明确拒绝尚不兼容的产品发布请求。
- 在训练开始前冻结数据集、成员和分区的摘要。数据处理和模型拟合一概只用训练集，验证集用于校准和阈值选择，测试集只做最终评价。
- 产出安全的模型工件，以及二分类指标、工作量（effort）指标、校准指标、区间和可复现证据。
- 实现训练和结果页面、基于角色的访问控制（RBAC）、取消和重试，并用真实数据、故障注入和独立环境完成验收。

## Capabilities

### New Capabilities

- `model-evaluation`：固定研究数据集上的逻辑回归与随机森林训练、校准、阈值选择、评估指标、安全模型工件，以及训练结果页面和用途权限。

### Modified Capabilities

没有。

## Impact

**数据库**

新增编号 0011 的模型迁移，保存模型运行、模型工件和训练任务相关的表结构；0001 到 0010 的迁移保持不变。降级时会在任何 DDL 之前检查整个目标路径，相关的模型运行、工件、训练任务和受影响的旧表或引用必须为空。

**后端**

新增名为 model.train 的可靠训练任务和受监督的 CPU 子进程；补齐 A20、A21、A23 的训练、详情、插件和运行目录能力，A22 明确拒绝尚不兼容的产品发布；同时实现训练和结果页面、基于角色的访问控制（RBAC）、取消和重试。

**存储与资源**

训练依赖使用独立的 modeling 依赖组，只使用有界的 CPU，不使用 GPU，也不下载模型权重。模型目录对 Worker 可写、对 API 只读，数据集目录只读；正常数据卷保留，现有的初始化器不得递归改动它。

**不在本次范围内**

不把旧标签、旧历史或候选资格晋升为生产用途；不实现语义模型、其余六个模型、未知格式导入或 main 分支维护。质量线未决的部分继续保留。
