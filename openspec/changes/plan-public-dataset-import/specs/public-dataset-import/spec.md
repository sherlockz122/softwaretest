## ADDED Requirements

### Requirement: 来源自描述

每个可导入的公开数据来源 SHALL 提供一份适配器声明，写明原文文件名、列映射、行键、事件时间列、标签列、许可标识与支持的能力位。

导入 MUST 依据适配器声明进行，不得在代码里散落某一来源的列名。

#### Scenario: 有适配器声明

- **WHEN** 导入一个已有适配器声明的来源
- **THEN** 系统按声明读取列、校验键并写入资产清单

#### Scenario: 缺少适配器声明

- **WHEN** 请求导入一个没有适配器声明的来源
- **THEN** 导入被拒绝，并指出缺少哪一项声明

### Requirement: 导入前体检

导入 MUST 在写入资产之前完成结构、键、数值、时间与许可五项检查，全部通过才允许落盘。

任一项不通过时 MUST 整批拒绝，不得留下可被误用的半份资产。

#### Scenario: 体检全部通过

- **WHEN** 一份来源的两个表键完全对齐、数值有限且非负、标签只取两值、许可与来源记录一致
- **THEN** 导入生成内容寻址的资产目录并写入清单

#### Scenario: 键对不齐

- **WHEN** 两份来源表存在对方没有的行键
- **THEN** 导入失败并返回缺失或冲突的行数，不写资产目录

#### Scenario: 单一类别

- **WHEN** 某个项目组里所有行标签相同
- **THEN** 该项目组被排除出可研究项目清单，其余项目照常导入，报告写明排除原因

#### Scenario: 许可或来源对不上

- **WHEN** 许可标识不是允许值，或来源记录与实际文件摘要不一致
- **THEN** 导入失败并指出不一致的字段

### Requirement: 资产不可变与幂等

资产 MUST 以内容寻址目录存放，导入完成后不得原地改写。

同一份来源重复导入 MUST 得到同一资产标识，或明确拒绝并说明已存在，不得产生两份内容相同而标识不同的资产。

#### Scenario: 重复导入同一来源

- **WHEN** 用同一份来源与同一版本适配器再次导入
- **THEN** 得到相同资产标识，已有资产内容不被改写

#### Scenario: 路径越界

- **WHEN** 导入目标目录落在允许范围之外，或路径含符号链接
- **THEN** 导入在创建任何文件之前被拒绝

### Requirement: 口径随资产走

资产清单 MUST 记录适配器版本、口径版本、能力位、限制清单与语言范围。

读取方 MUST 能只凭资产清单判断该资产是否可用于某一用途，不需要回看代码。

#### Scenario: 读取能力位

- **WHEN** 数据集创建请求引用一份资产
- **THEN** 用途门槛按该资产清单里的能力位判定，而不是按代码常量

#### Scenario: 口径与实现不一致

- **WHEN** 适配器版本升级导致列语义变化
- **THEN** 新资产使用新的口径版本，旧资产的清单与哈希保持不变

### Requirement: 导入由管理员在命令行执行

导入 MUST 由具备管理角色的人在命令行发起，并通过受监督的子进程与超时上限执行。

应用进程 MUST NOT 提供上传或自动下载入口。

#### Scenario: 管理角色执行导入

- **WHEN** 管理员执行导入命令
- **THEN** 命令在时限内完成或明确超时，输出资产标识与体检摘要

#### Scenario: 非管理入口

- **WHEN** 应用侧收到上传数据集的请求
- **THEN** 该请求不被本能力处理，接口保持现有的「引用已存在资产」语义
