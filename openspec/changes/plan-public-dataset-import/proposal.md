# Change: plan-public-dataset-import

## Why

产品里已经能选到公开数据资产，但只认一种：运维用专项脚本把 ApacheJIT 下载、审计、封装进资产库，用户再从数据集页挑那份资产。换一个公开数据集就没有入口，格式与口径也只写在阶段报告里，新来的人看不出某一份资产到底算不算合格输入。

十七项改进方向里的「可加载已有公开数据集」要的就是这一层：把导入做成有规格、有体检、有版本记录的能力，而不是一次性的专项脚本。

## What Changes

- 定义导入规格：每个公开数据来源写一份适配器声明，说明列映射、行键、时间列与标签列的含义、许可以及能力位。
- 导入前先体检：结构、键、数值、时区与许可全部通过才落资产；任何一项不过就整批拒绝，不留半份资产。
- 资产带自证信息：适配器版本与口径版本写进清单，能力位与限制清单随资产走，换个来源也不会把旧口径套上去。
- 导入只走命令行，由具备管理角色的人执行；应用内上传与服务端自动下载列到后续批次。
- 补一份格式与口径说明，把原文列、派生文件、清单字段与判定规则写成人能照着用的文档。

## Capabilities

### New Capabilities

- `public-dataset-import`：把已有的公开数据集按自描述规格导入为不可变资产，并在导入前完成结构、口径与许可体检。

### Modified Capabilities

无。数据集创建接口、训练链路与既有资产的内容都不变。

## Impact

- 受影响的本目录文档：`docs/03-数据与算法规格.md` 的公开数据口径、`docs/05-测试与验收计划.md` 的数据集验收条目、`docs/07-需求设计测试追踪矩阵.md` 的 US-08 与 US-09 行。
- 新增文档：`docs/development/公开数据集导入方案与格式口径.md`。
- 关联用户故事：US-08（不可变数据集）、US-09（分区与标签）、US-15（模型运行与工件）；对应十七项改进里的「可加载已有公开数据集」与「现成模型入池」两条的前置。
- 非目标：这次只出规格、方案与体检规则，不改实现；不做服务端出网下载；不做浏览器上传入口；不把多个来源的标签语义合并成一套；不重算已有资产的内容，也不改写已发布数据集的哈希。
